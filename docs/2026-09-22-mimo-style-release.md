# MiMo自由格式风格采用记录（2026-09-25，已采用）

新版v10已通过开发、新主题确认和实现者复核，默认学习方法已切为direct_free。五份已验证Spec独立加入正式风格库，旧风格保留。两轮评测模型均为mimo-v2.6-pro；DS结果只保留为研发历史，不参与采用判定。

## 已完成的改进

提取声音与表达机制，不强制十个维度，不继承原文具体论点、剧情或结尾方向；第一人称判断、自嘲与亲历事实分开处理。400–600非空白字符目标保持不变，过长时压缩、过短时依据证据补充，最多一次修复。格式、长度和去污染先过Spec检查，再生成正文，避免已知不合格候选继续消耗请求。

MiMo结构化学习与评分已使用[官方JSON模式](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/structured-output)，语法约束之外仍检查字段、证据和语义。大纲、正文与旧Markdown提取仍用普通文本。运行与评测共用实现；请求快照记录response_format，模式变化拒绝复用。裁判文字、生成包装、确定性字数政策与先登记采用门槛未改。
