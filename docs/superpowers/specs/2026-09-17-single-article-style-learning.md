# 单篇风格学习与对照评测需求（2026-09-17）

状态：已实现并完成三组真实模型对照。候选未满足采用条件，默认保留legacy；完整结果见 ../../2026-09-17-style-learning-results.md。后续多文章过拟合/欠拟合实验不在本轮范围。

## 目标与边界
将单篇文章转化为有依据、可迁移的写作指令，为后续大迭代留下可复现对照。保留 styles/*.md 的纯执行指令接口、CLI/REPL 命名和恢复流程；不改历史风格、冻结样文、原始人评、.env 或模型配置。

## 方法
1. 证据分析：读取完整单篇，输出结构化特征记录（观察、原文短摘录、规则、适用条件、支持程度）。维度只作检查清单；不凑十节、不从未出现推断禁令，不扩展到作者整体画像。
2. 指令编写：程序去掉原文摘录与观察描述，只传规则、条件和支持程度。模型输出 JSON 信封，程序仅提取 spec Markdown 用于保存和生成。Markdown 标题、数量、顺序自由；不要求固定禁令。
3. 质量边界：原文摘录需在输入中可定位，结构/空值/类型由程序校验；这不能证明规则语义正确。每阶段最多一次针对诊断的修复。400–600 非空白 Unicode 字符为目标，完整沿用既有分档和最低字数扣分；修复后仍偏短/偏长但可用时明确警告，不填充、不截断。空内容、代码围栏、只有标题、异常超长（>1000）不作为正式风格。
4. 留证：日常学习的阶段请求、输出和错误保存在 outputs/style-learning/ 独立记录（不含密钥/端点）；失败不进入命名/正式保存。恢复待命名结果时再检查可执行文本的机械有效性，不强改旧风格。
5. 写作端：核心规则优先采用，条件策略仅在适用时使用；新任务明确要求和事实边界优先，不将所有观察升级为硬约束，不虚构经历、引用或数据。

## 提示词资产
冻结当前单阶段提示词到 eval 的独立 fixtures 目录；新增证据分析提示词；将 learn_style.md 改为指令编写提示词。具体全文以受版本管理的提示词文件为准，评测运行额外冻结请求快照。

## Eval 变更
- Rubric B v2：coverage 从十标题格式覆盖改为有证据的重要机制覆盖；actionability 奖励明确动作与适用条件，不能奖励绝对禁令；保留其余字段与确定性长度评分。新旧评分语义变更，不能把 coverage v2 直接与原人评作误差校准。
- 机械检查移除十标题通过判据，报告空值、执行文本有效性、字符数、长度分档、原文重合线索；重合不等于污染，零重合也不等于无污染。
- 当前模型下对相同单篇输入重新运行旧单阶段和新两阶段；使用同一个新 Judge 匿名分别评分。五份冻结样文均可自动使用，不追加用户人评。
- 换题验证：每份 Spec 用同一生成包装、同一新主题生成大纲与正文，再由不知版本的 Judge 对照原文评价风格保真、任务遵循、去污染。第一轮各一份，记录单次采样与同模型裁判局限。
- 每次模型请求存检查点；同 run_id 续跑，输入/提示词变化必须新 run_id；并发不超过3。报告调用次数、时间、字数、维度分数及失败，不把失败当成功。
- 采用标准：新方案 Spec 非长度均分不下降、去污染不下降，换题写作综合分不下降且无新增严重污染；若结果混合则按维度如实报告，保留旧提取路径作为默认/回退，候选仍可实验。若新方案达标则切换默认。样本小，不宣称统计显著或人评通过。

## 验证与完成标准
离线测试覆盖证据虚构、无效 JSON、重试上限、摘录隔离、自由格式、长度边界与失败不入库；CLI/REPL 共用提取路径，已有会话兼容。cargo test --lib、二进制构建、必要终端回归、真实 API 对照、输入快照续跑检查、git diff 审查与本地提交。同步任务、风格/评测说明和最终实验结论。

## 有界补充对照：自由格式单阶段
为区分“取消固定栏目”的收益与“两阶段分析”的收益，增加一个自由格式单阶段候选 `learn_style_direct.md`。它在一次调用内核对证据、去内容依赖，输出与编写阶段相同的 JSON 信封；复用执行文本校验、最低字数评分和最多一次诊断修复。没有外显证据分析记录时 analysis 明确为 null，不伪造证据。该对照完成后停止扩展实验，按同一采用标准选默认方案；两阶段无论是否采用均保留可复现入口。
评测通过 EVAL_LEARNING_METHOD=direct_free 使用独立 run_id；省略该变量仍跑两阶段。旧方案请求完全不变时复用检查点，保留来源 SHA256。本次最多比较固定十节单阶段、两阶段初版/修正版、自由格式单阶段，不进入多文章实验。
