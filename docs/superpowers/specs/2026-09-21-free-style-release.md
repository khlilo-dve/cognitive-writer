# 自由格式风格学习优化与默认切换（2026-09-21）

状态：2026-09-25已完成MiMo v10开发与新主题确认，已切默认并导入五份独立风格；结果见docs/2026-09-22-mimo-style-release.md。以下保留原先登记的方案和迭代经过。按上下文将“不固定，必须用十个维度”理解为自由组织、不强制十个栏目。单篇学习范围不变，不开展多文章学习。

## 方向
以已有direct_free单次调用为主：保留较好的声线捕捉，去掉把样文剧情/推导路线复制为规则的倾向；将数据、引语、场景、第一人称经历等依赖素材的写法明确设为有素材或获准虚构时才使用。保留核心素材的责任必须高于“少写背景/略去身份”等风格偏好。两阶段保留为实验选项，不额外增加日常调用。

## 固定评测与验收（先登记，再运行）
不修改Rubric B v2、Transfer v2、计数规则或生产生成包装来帮助候选获胜。旧十节提示词、旧产物、人评只读。每次提示词变动新run_id；相同旧请求可精确复用并记录来源。
开发对照：五份样文分别用新版学习，旧方法先按冻结提示词在相同模型提取，之后精确复用不变请求；在当前相同模型下生成旧/新各五篇严格素材、五篇创作文章，使用已冻结修理日任务和同一裁判。记录Spec质量与五维独立迁移评分，不合成总分。

“符合预期”的发布门槛：
- 五份新Spec全部为有效自由Markdown，400–600非空白字符，Spec可执行性/特征捕捉均分≥4，去污染每篇≥4；不强制标题数。
- strict和creative分别：风格保真≥4、自然度≥3.8、原文独立性≥4.8、核心素材完成≥4.8；事实合规strict≥4.4、creative≥4.8。不得有任一篇风格/原文独立/事实/素材完成≤2；每种任务至少4/5篇满足600–900字符。
- 与旧版比较分项差异和胜平负；达到上面的实用标准即可采用，不要求所有随机单项都超过旧版，也不将多个维度合成有利的总分。
- 开发门槛通过后，冻结候选并在另一个事先定义的“社区共享雨伞试点”题材上做相同旧/新×五风格×两权限确认（不再重新提取）；同样门槛通过才切换默认。若确认失败，保留结果并继续修正，下次确认需新任务，不能称已看过任务为留出验证。
- 模型评分有已知波动，同模型Judge、五个开发样文、少量题材不能证明统计显著或替代用户人评。达到门槛表示本阶段工程预期达标，不宣称普遍优于旧法。
