| 5 | 400–600 |

## 工程结果

- A：REPL 唯一 stdin 读取器贯穿恢复提示与主循环。学习提取后等待命名，重名/非法路径不覆盖、提取结果保留；删除须明确确认。EOF、Ctrl+C、/quit 保存等待态；/cancel 取消。写入中断不会破坏旧会话，保存失败的退出请求留在交互中。旧大纲可继续正文；换风格成功后才一起更新风格元数据与正文。
- B：io/refine/utils 的公开错误及 learn/update/REPL 调用方统一 AppError，保留错误分类；旧兼容包装 API 保留但不再用于子命令错误传播。
- C：intent 按分类、快速预检、历史测试提取职责拆分，原公开路径重导出；styles 分离名称与摘要；eval 分离旧批量 API。所有模块在 lib.rs 注册，main 只负责分流。除 REPL 编排层外，Rust 模块均≤500行。

验证：`cargo test --lib` 为177通过、7个真实模型入口默认忽略；`cargo check --bins` 通过。`scripts/verify_repl_terminal.py` 使用临时目录和本地 HTTP 模拟，11项真实PTY检查通过，包括读入/命名/删除/恢复/模型请求期间Ctrl+C、EOF、旧大纲继续及文件大小限制故障注入。结果见 [终端回归](../eval/repl-terminal-validation.json)。
