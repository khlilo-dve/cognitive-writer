# 全文上下文与局部替换（2026-09-16）

## 问题和结果
原 REPL 局部修改把模型返回的全文直接替换原稿，可能改到用户未指定的段落。现按用户审核的方案：完整文章作为上下文，模型仅返回指定块，程序按原始位置替换。

## 使用
- “第二段加案例”“第一段和第三段缩短”“‘小节’下面第二段改短”可以定位正文段落；引号使用中文双引号等受支持格式。
- 标题不计入正文段落序号；列表、引用、代码、表格作为独立块。/blocks 可查看 B 编号与原文摘要。
- 重复引用或无法明确的范围会追问，回复 B2 或 B2,B4 继续。排除项、参考项与修改目标混合的复杂指令会要求明确选择。
- 追问时 /cancel 只取消本次修改、保留原文；/quit 和中断保存待定位指令与候选。/undo 撤销上次成功局部修改，重启后仍可使用。

## 修改边界
完整原文、块索引、允许编号、风格和原始修改指令一同传给模型。响应必须包含且仅包含所有指定编号，每个编号只能出现一次。程序复制范围外原始字节，不重新格式化全文；所有目标通过校验后一次性应用。

另外比较未编辑块的位置与 Markdown 解析事件，拒绝未闭合代码围栏、改变邻块结构或影响其他引用链接的结果。模型返回额外块、遗漏块、空内容或错误 JSON 时，旧稿不变。正文修改不改变原有文章 slug，只有标题变化时更新；撤销同时恢复旧 slug。

原始 HTML 替换不受支持，模型须返回 Markdown；空替换不会被当成删除整块。成功后显示修改位置、修改前片段和修改后全文，保留一份前稿用于单步撤销。

- scripts/verify_style_selection.py：11 项通过；scripts/verify_repl_terminal.py：17 项通过。
- 测试使用本地 HTTP 模型桩和隔离临时目录。断言模型收到完整文章；独立按原文字节偏移重建预期结果，与最终正文完整比较，覆盖中文及 CRLF。

范围仅为 REPL 正文审阅阶段局部修改；现有 AI_EDIT 文件编辑入口与整篇换风格流程保持原样。本次验证不代表真实模型改写质量评测。
