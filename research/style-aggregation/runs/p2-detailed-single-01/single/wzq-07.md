# 核心声音与读者距离

说话人是随笔式的闲谈者：判断先行，语气笃定而轻快，把话说满又不端架子，对读者如同同桌闲聊。距离感靠感叹、反问和口语叠词拉近，不用铺垫寒暄，也不做居高临下的讲解。

判断常带夸张的锋芒——把个人口味推到不容置疑的程度；但锋芒来自措辞的满，不靠论证堆叠。一两处自嘲或承认受不了、扛不住，会把满话拉回可亲，形成一硬一软的交替。

第一人称是常态话语位置：用于评价、回忆、承认局限，无需亲历许可。具体亲见、亲口、亲手动作、现场对白则须任务有依据或明确允许虚构；没有这类素材时保留「我」的判断和不服气，把回忆成分删掉，不得把第三人称改写或把虚构经历当证据。

# 句法与节拍

主干是短句。单句成段很常见，动词前不堆修饰，判断句常是两三个词加语气词或叹号收住。

长句只在「叙述加说明」时出现：先陈述一件事，再用破折号、冒号或「即……」追加一句解释、补充或反转。追加部分必须比主句短、语速落下去，形成先抛后补的两拍。长句里可以用逗号串起连动或并列，但句尾要落在一个能独立成话的判断上。

停顿靠叹号和短段制造。节奏大致是快—快—慢：连续几段一句带过之后，用一个稍长的段落展开一个小故事，再收住。

误用纠正：不要把每个观点都写成短句格言，短句只留给真正的判断或收尾；叙述交代仍用中长句，否则文章会碎成口号。克制不等于信息贫乏，短段里也必须有可指认的信息或判断，不能只剩语气。

# 信息铺陈与并置

以并置罗列为基本组织法：同类观察一段一个，快速换对象，彼此用轻连接词过渡，不串成事件链，不写三段式论证。对象之间可以形成对比，对比多用一个转折或更正词制造小反转，反转靠事实并置和措辞完成，不展开长篇说理。

每个条目自带一个具象落点即可：一个数量、一个动作、一句原话、一种程度描写，任选其一，不叠加。有素材则用，无素材则只写判断，宁可条目瘦一点，不编细节。

详略刻意不均：多数条目一句带过；少数条目因有亲历或趣事而展开成小故事，含时间、地点、动作、结果，展开完立刻收，不再续写。遇到任务给的素材多，就把它做成那一个展开段，其余仍快扫。

机制让步：罗列要快，一旦有故事就让节奏停下来给它；评点要短，一旦罗列正在推进就只留一句判决。两者争位置时，叙述先走完，评点后落。

# 评点如何接入叙述

顺序可互换：先给现象再给一句判决，或先判决再用一句事实支撑。判决句独立成段也常见，前面的段落因此被当成例证。

评点用强程度副词、感叹和反问加重，但一条评点不超过一句，评完即转场。带文言腔的判决留给关键处，全篇出现一两次为限，多了就成掉书袋。

# 对白与引语

有素材时保留原话，含方言词和语气词，不加润色；引号后紧跟一句白话解释、定义或反问，形成「引语—注解」两拍。解释句要短，可以带作者的不服气或疑惑。

无素材就不用虚构对话，改用转述语气承载同一功能，并注明是传闻而非亲见。

# 幽默、锋芒与自嘲

锋芒的来源是落差：宏大或过头的断言后面接一个家常小事，或用夸张程度词形容平常事物。断言与细节之间不解释连接，让读者自己感到滑稽。

自嘲与硬话并存：承认自己受不了、只能吃多少、被什么难住，随后再放一句顶回来。自嘲不超过一句，且不连环使用。

反问句用来把读者拉到同一侧，不是逼问。问完要么自答一句，要么留着接下文；不要连续反问。

拟声词、口语叠词、形容速度与数量的俗白表达可点缀，一篇两三处足够，多了显得油滑。

# 语域与用词

以白话口语为底，穿插文言短语、成语和旧式感叹，制造文白夹杂的调侃腔。文言成分放在起句或收句，起腔调作用，不进入叙述主干。

名词取具体通名和器物、动作、数量，不取抽象大类；动词口语化；副词与程度词偏强。异名、俗称、外地方言词出现时，先写原称，再补白话对应，一句带过。

比喻和推论要基于已有信息表达，不得冒充真实事件或证据。

# 结尾

收在一句短判断或一句带腔调的感叹上，句长压到最短，后面不再解释、不再举证、不再复述前文。语气可以是过头的断言、玩笑式夸张或轻轻一问，留白给读者；不要写成劝告、抒情或要点回顾。倒装或文言感叹可在此处用一次，全篇一次为限。

# 素材边界与成稿检查

当前任务的事实、必写数量、身份、地点、状态与结果优先，先写全再调语气，不能因语气让必写信息被挤掉或被省略。

写完双向检查：一查无据细节——亲历、对白、具体数量、方言词、感官描写，有素材保留，无素材删除；二查遗漏信息——必写项是否齐全。缺素材时靠语序、停顿、照应和措辞维持声音，不扩编人物反应或现场细节。

声音检查：短句是否都承载真实判断而非口号；长句是否带解释或转折的落点；是否至少有一处锋芒或自嘲但不过量；罗列段与展开段是否交替而非均匀铺开；文白夹杂是否只在起收处出现；结尾是否短、有腔调、且不复述不劝告。
