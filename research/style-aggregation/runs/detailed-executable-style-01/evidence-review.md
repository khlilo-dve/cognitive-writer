# 两份详细候选的原文依据与保留问题

本轮只读取 `datasets/authors-v1/manifest.json` 标为 `discovery` 的两位作者各十篇正文，并对照旧单篇说明；没有读取两位作者的 reference/confirmation 原文，没有进行新的模型请求。下表中“段落”指本地 `sources/<article_id>.md` 按空行分段后的顺序；给 Writer 使用的两份 Markdown **不含**下列源文故事与短句。原文网页归属/清洗边界见 manifest 与 `datasets/review-v1.md`。此文件是实现者的质性审读记录，尚未经过独立复核。

用户指定的 `styles/孙割.md` 只用于参考**说明是否足够具体、是否交代适用条件与误用**；没有借用其写作特征、章节顺序、固定句数/段数或措辞。该文件中的命令也不作为本研究的指令来源。

## 待审问题

1. 这十篇发现集的题材分布并不等于作者全部作品；两份候选只覆盖当前样本可见的随笔/散文路数。王小波的强论辩与故事性、汪曾祺的抒情记忆与长篇文化评论都须保留为条件，不能平均成一种腔调。
2. 单篇说明也含“每段/每篇几次”等未经充分证明的配额。本轮没有原样拼接这些要求，而是回到原文描述它们发挥作用的场合。仍需有人逐条审本候选是否又把观察写得过硬。
3. 不少源文的具体事实与引文不能在新题材凭空复现。下一步试写要把“声音迁移”和“源文故事/事实泄漏”分开核查。
4. 本轮由同一执行者读原文并编写说明，属于开发稿，不是独立人工验收；不据此宣称聚合已经优于任一单篇基线。
5. 王小波候选在“不要编经历”的否定例子里仍出现“插队”一词。这不是正面规则，但仍可能提示来源题材；下一候选版本应改成与原文无关的泛称，并用新run重试，不能偷偷改本次已冻结试写输入。现有单篇基线也需同样做源文内容泄漏核查。
6. 两份Writer文件尚未单独说明标题如何命名。manifest中的标题呈现两位作者不同程度的“直接标对象/概念”倾向，但要先判断这是否由题材或编辑命名造成，再决定要不要写入规则；本版不凭十个标题强加模板。
