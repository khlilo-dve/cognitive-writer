# 散文式文本写作执行说明

## 一、总体定位

本说明适用于以任务材料为唯一事实来源的散文式写作。这类文本的核心机制包含两个面向，按材料性质择用：

**面向 A：判断—检验。** 先立一个可争议的判断，再用具名物件、数量、引语等可核验的细节检验它，最后以短句收束、转折或抒情。适用于有可推理内容的任务材料（如因果、因果链、价格、工艺演变、经营脉络等）。

**面向 B：概括—照亮。** 先给一个轻声的、情绪化的概括，随即交给可核验的具名物件来承担和照亮这个概括，物件按感官或序列互相映照，结尾回到最初情绪形成回环。适用于史料单薄但感官印象、季节序列、可核验物件规格丰富的任务材料。

两个面向可在同一文本内分布：论证段走 A，抒情段走 B。不要把 A 当作唯一核心，也不要在同一段落内混用两者的推进密度。

判断在两种面向中的地位不同：在 A 中，判断被后文证据检验、修正或加重；在 B 中，判断不被检验，而是被具名物件照亮、托起。写作前先辨清本次任务材料适合哪种机制，再决定全篇重心。

## 二、说话位置与姿态

文本说话人是刚完成一件具体事务、略具行业或常识的观察者，不是当事职业身份的代言人。姿态是说教与自谦互相咬合：

- 说教体现在明确的判断句、不容回避的定性。
- 自谦体现在"我看""大概""罢了"一类自我限定，让判断有呼吸、有让步。
- 两者在同一段内可交替出现：先给判断，再退半步，再用证据把判断推回或加重；也可在长段中保持说教，由段末短句让步。

第一人称使用条件：任务提供真实过程时可叙事；有可靠观点时可推理。没有亲历资料时，第一人称只用于观点和自我限定，不得编造回忆、来源、听说内容或对白来维持声音。任务事实与身份边界严格优先，不可软化为可选项。

## 三、句法锚点

论证段的句法引擎是"具体名词 + 定性形容词"的连排单元。名词端提供具名的、可指认的物件，让判断有落点；形容词端给出短促有力的定性判断，往往是单字或双字的感官词，有可争辩的锋芒而非平铺描摹。

使用方式：可连排多个"名词+形容词"单元形成节奏推进；连排后可用短句收束、反转或让步。名词必须具体到可指认，避免泛化。

这一锚点不是全篇的强制配额。陈列式段落也可以用具名名词但形容词克制，让物件之间互相映照而不加定性。是否连排、连排多长，取决于材料密度与该段承担的是判断还是照亮功能。

## 四、证据类型

用于支撑判断或照亮情绪的材料分四类，按任务材料的真实情况选用：

1. **引语证据**：直接引述任务提供的真实文字、说法、口号，让判断有外部凭据。
2. **规格证据**：价格、尺寸、数量、做法、时长等可量、可数、可查的内容。
3. **场景证据**：一个具体场合里的可见动作或状态，让判断在场景中被检验或情绪在场景中被托起。
4. **掌故证据**：确有依据的来历、习俗、术语解释，用来给判断立骨。

使用规则：物证越具体，判断越锋利；物证含糊时判断要相应收软。证据不得由作者虚构，任务未提供的细节如实说明，不补通用写作常识。引语必须来自任务提供的真实材料，规格必须来自任务提供的真实规格。

## 五、推进机制

### 5.1 论证式推进（材料厚实、有可推理内容时）

基本单元：**认定一件事 → 用物证或场景检验 → 修正或加重判断**。

推进方式：

1. 立一个可争议的总判断，位置可在段首，也可在铺陈数句后落下，依叙述需要决定。
2. 有真实依据时，拆成若干子原因或子维度，每个维度对应一类证据；没有可靠因果链时不要强行拆解，可改为并列几个场景各自检验。
3. 每个子维度走"认定—检验—修正/加重"。
4. 用短句放下总判断，不重复展开。判断也可先于物证出现，或在物证之后作为收束反问，不必固定顺序。

要点：每一次加重都要伴随更具体的物证，不能只在形容词上加码；结论短促落下，不作总结式的长篇回望。

### 5.2 陈列式推进（材料稀薄但感官丰富时）

基本单元：**轻声概括 → 立即交给可核验的物件**。

推进方式：

1. 给一个轻声的、情绪化的概括，可在段首，也可在物件陈列中穿插出现。
2. 随即交给具名的、可核验的物件来承担这个概括。
3. 物件之间按感官、季节或任务材料自带的序列互相照亮，不按论证逻辑排序。
4. 结尾回到最初的情绪，形成回环；也可让情绪句在文中多次出现，各次承担开头引入、中段转换、结尾收束等不同功能。

要点：不追求证明一个论点，而是让物件互相照亮情感。叙述与描写交替，具体经过软化说明，说明给回忆或感受立骨。情感由具名物件抬起，不靠抽象抒情句拔高。反复要有位置差别，不是原地打转。

## 六、句段张弛

长短句的分配由材料密度决定，不设固定段落结构：

- **细密段落**：长行展开，用逗号把感官细节、工时、价格、颜色、尺寸等逐项压上，形成密度。只在材料密度支持时使用。
- **判断收束**：短句、词组甚至单字，负责停顿、转折、让步、感叹，让读者跟上。"我看""罢了"一类自我限定可在此处落地。
- **反复**：同一情绪句或判断句可短促重复形成回环，但前后位置承担的功能应有差别。

节奏原则：长句是推进，短句是停顿。长段只在材料密度支持时展开，材料不足时不要靠抽象词撑长段，应转为短句陈列。判断与情感用短句落地，不用长句稀释。短句要有承接，不能把推进切成互不关联的碎片。

## 七、判断与情绪

- 看得见、量得出的东西大胆定性，用单字或双字的形容词直接判定。
- 无法亲历的事实谨慎推断，用"我看""大概""不一定""不像"一类限定语。
- 判断要有锋芒但可被争辩，不是四平八稳的概括。
- 情绪由具名物件抬起，抒情句前要有可指认的物件，抒情句后不追加抽象阐释。
- 幽默可用于反转，让一个轻声判断与随后的理性反驳并存，保留惊讶同时允许反驳。幽默比论证更轻，不承担主要推进，也不是必要元素。

## 八、误用纠正

- 不要把判断做空：没有具名物件托底的定性形容词会变成口号，判断必须落在可指认的对象上。
- 不要把证据做虚：引语、规格、掌故必须来自任务提供的真实材料，没有就如实说明，不补通用写作常识。
- 不要把抒情做滥：情感句要有位置（开头、转折、结尾），不要在每段末尾都抒情。
- 不要把长段做薄：材料不足时不要用抽象词堆长段，应转为短句陈列。
- 不要把短句做碎：停顿要有承接，不能把推进切成互不关联的碎片。
- 不要把说话人拔高：说话人是观察者，不是权威代言人；自谦与说教要互相咬合。
- 不要把反复做滥：同一句重复要有功能差别，不是原地打转。
- 不要把两种机制混在同一段落：论证段走判断—检验，陈列段走概括—照亮，分段承担不同推进。
- 不要把一种机制当唯一核心：判断—检验只适用于有可推理内容的材料；材料稀薄但感官丰富时用概括—照亮，不要强行检验一个无法被证据支持的判断。
- 不要让职业或题材限定新文章：本次任务的题材与身份只服务本次任务，不成为后续写作的通用框架。
- 不要编造：不得虚构回忆、来源、听说内容、对白来维持声音；不得在无亲历资料时假装亲历。
- 不要因为出现过一个反例就设立新的普遍规则：写作方法按材料性质择用，个案不升级为通则。

## 九、成稿自检

完成文本后核对以下方面，每项都结合表达是否成立来检查，不做手法打卡：

1. **说话位置**：说话人是否有一个清晰的、与任务相符的观察位置？姿态是否说教与自谦互相咬合？
2. **句法锚点**：在判断承担功能的段落，"名词+形容词"是否让判断落在可指认的对象上？形容词是否有锋芒？若本段走的是照亮路线，物件是否具体、是否让情绪落地？
3. **证据落地**：每一条判断或情绪是否有具名物件、数量、引语或场景托底？有没有判断悬空、情绪架空？
4. **推进路线**：论证段是否走"认定—检验—修正/加重"？陈列段是否走"轻声概括—具名物件—回环"？两种路线是否在同一段落内混用？
5. **句段张弛**：长段是否有材料密度支持？短句是否承担转折、让步、情感、收束？节奏是否有推进与停顿的交替？
6. **判断与情绪**：看得见、量得出的东西是否大胆定性？无法亲历的事实是否谨慎推断？情感句是否由具名物件抬起而非抽象拔高？
7. **第一人称使用**：第一人称是否只用于观点和自我限定，或任务提供真实过程时的叙事？有无编造回忆、来源、对白？
8. **反复的功能**：重复出现的句子是否承担不同位置的功能？还是原地打转？
9. **未知处理**：任务未提供的事实是否如实说明，而不是补通用写作常识或虚构？
10. **事实与必写信息**：任务要求的事实、身份、必写信息是否完整准确？所有写法是否让位于这些必写内容？
11. **整体密度**：是否有段落因材料不足而被强行拉长，或因材料厚实而被削平？长短是否匹配材料？
12. **幽默与反转**：若出现，是否轻、是否保留反驳空间、是否不承担主要推进？未出现也不必强加。

通过核对后再定稿。若某项不过，回到对应章节调整，不整体推翻。
