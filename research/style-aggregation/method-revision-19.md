# 2026-10-24：逐篇观察与增量综合的风格学习 v2

前版 `voice-learning-pilot-01` 已保存 `reject_for_product_and_writer`，不得将其五份通过结构检查的 Style 当作产品候选。失效点是：直接把多篇全文交给一次综合，模型仍将原文故事/引句写入 Writer 文件，且增加文章后没有说明旧规则的去留。引文逐字存在只证明定位，不证明语义推断。

本版先对六篇 discovery 文章**逐篇**提取可定位的写作操作卡片，随后每位作者按相同的 1→2→3 顺序**增量编写**。新增文章可以保留、收窄或撤销旧规则，但每条旧规则必须在变更表中交代；新的规则必须指向已经逐字核验的卡片。`Style.md` 与来源卡片分开；程序拒绝从原文拷入较长连续片段或把卡片引文原样写入 Style。这些约束只防明显泄漏，语义是否成立仍要人工审原文与说明。不存在“越长越好”“每条规则必跨题材”或机制数量配额。

沿用前版六篇文章及顺序，另起 `voice-learning-incremental-01`，不拼接前版候选。先用 Pro 结构化模式取各篇卡片，再用 Pro 推理模式编写 k1/k2/k3；每阶段最多一次结构或证据修复。run 最高占用 ¥6，仍受已批准 ¥100 总额约束；任何失败如实保存，不为了达成 6/6 改写同 run 的提示词或验证器。新增第三篇后重点读：之前正确的写作机制是否被保留，误判是否被有理由地修改，条件差异是否仍在，原文内容是否进入 Writer 文件。通过这些开发检查后才考虑从三篇扩大到五篇或十篇，不能把小样本合格叫作完整系统。
