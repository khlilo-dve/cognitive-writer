# 风格文件本身的问题：第一轮质性复核

这是对已冻结文件的**定向诊断**，不是两位作者十篇全文的完整人工标注，也不评选聚合与单篇的胜负。比较对象：`pragmatic-profiles-recovered-01` 两份探索性聚合说明、`p2-detailed-single-01` 的 `wxb-07` 和 `wzq-07` 单篇说明，以及同题生成稿 `pragmatic-generation-01` 的 `article-001/007/025/031`。源文 `authors-v1/sources/wxb-07.md`、`wzq-07.md` 用于校核语境，不能凭单篇代表作者全集。

| 观察 | 为什么影响 Writer | 需要怎样改 |
|---|---|---|
| 王小波聚合说明列六种技巧，却没有把“第一人称与读者距离”“叙述后怎样转入判断”“材料不足时如何保留声音”等连起来。单篇 `wxb-07` 说明已经对这些问题有具体处理。 | Writer 可能只学到“开假命题、做夸张例子、末尾开放问题”等动作，写成辩论模板。 | 从十篇原文核查后写出整体声音与动作之间的优先级；哪些场景只需平实叙述、哪些才允许反讽或自嘲，要明示。 |
| 汪曾祺 `wzq-05b` 单篇说明描述的是当面讲谈、判断与解释相接；`wzq-07` 则偏食物见闻的松散罗列和短评。同一作者不同题材的路线明显不同。 | 把两种路线压成一套“短句、物件、设问、收尾”的通用步骤，反而会抹掉作者怎样随题材变换写法。 | 作者级文件写共同声音，并分开说明评论、见闻、记人等场景的操作与例外；用十篇原文核查，而不以两份单篇说明为最终证据。 |
| 汪曾祺聚合说明中的“三到八字短句”“每篇两到三次设问”“每个判断一到两个细节”等精确配额缺少当前证据支持。 | Writer 容易为了满足次数制造句型和细节。 | 把配额改写为节奏、转进与信息密度的条件说明；若原文确实有稳定偏好，再以多个来源片段说明，不将观察硬化为命令。 |
| 王小波聚合工具柜稿 `article-001` 被分成五个 `##` 小节；原文 `wxb-07` 是连贯段落，单篇说明明确说“不用小标题”。 | 这不单是标点差异，而是成稿的组织方式会被通用说明文格式接管。 | 在新的作者级说明中明确通常如何转段、何时可以例外；观察同作者其他原文后再决定是否设为默认。 |
| 汪曾祺聚合工具柜稿 `article-025` 写了“分格摆放”“登记簿上写姓名和借用日期”“柜面上的笔”等任务素材没有提供的细节。单篇对照 `article-031` 也出现了素材外细节，问题不是聚合组独有。 | 把“具体物件/动作”理解成“必须补造现场”，写法与事实边界互相冲突。 | 新说明要给出“有可用细节就落地；没有时靠选择观察角度、语序和语气，不补新物件/流程”的替代。试写时逐句核查具体增加了什么。 |

这四项来自可定位文件，说明下一步首先应修**文件内容与可执行边界**。它们不说明单篇一定更好，也不说明聚合必然失败。长度、规则数量和模型分数均不能替代对这些具体问题的判断。
