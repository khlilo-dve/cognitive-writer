# 候选语义复核材料
开发数据的实现者复核，不是人工盲测或独立确认；结构有效不等于语义正确

## pilot-00 / c0000 / distinct / voice
A：严肃判断用闲谈口气说出，作者站在读者旁边，不宣言、不煽动、不摆教导姿态，但句句带明确判断（条件：未限定）
B：以第一人称"我"作为叙述与判断主体，是冷静的在场者与评语者，不是抒情者（条件：未限定）
模型理由：左规则规定的是与读者的相对位置与口气：闲谈、不宣言不煽动不教导，但每句有判断；右规则规定的是叙述主体与情绪控制：第一人称'我'作冷静的在场评语者、不抒情。二者都含'在场''有判断'的成分，但一个约束语域与姿态、不限定人称，一个限定叙述人称与非抒情、不涉及闲谈口气，机制不相同。

## pilot-00 / c0012 / distinct / voice
A：允许第一人称判断随时出场，判断可以锋利，但锋利只来自措辞，语气平淡；不靠感叹号、程度副词或排比（条件：未限定）
B：读者被当作通情达理的熟人，可用"你"称呼、直接发问、请读者猜，但不煽情、不请求共鸣、不铺垫感动（条件：与读者直接交流时）
模型理由：f02管第一人称判断的强度来源与句式禁忌；f04管与读者直接交流时的关系设定（把读者当熟人、可用“你”、可发问），并禁止煽情求共鸣。一个针对“我”的判断语气，一个针对读者关系与互动方式，条件与机制不同。

## pilot-00 / c0024 / distinct / voice
A：谦抑词（自认所知有限、自认无能为力）与自信判断可并存且常相邻出现：先自我削一刀，再照样把话说完（条件：未限定）
B：不直接开骂，不用感叹号加力，不用反问连环轰炸（条件：讥刺时）
模型理由：f03（未限定）讲的是自谦语与自信判断可相邻共存的自我呈现机制（先削一刀再把话说完）；f14（讥刺时）讲的是讥刺场合的表达禁令（不直接开骂、不用感叹号、不用反问连环）。一为谦抑与断言的配伍，一为讥刺方式的克制手段，条件与机制都不同，且互不排斥。

## pilot-00 / c0036 / distinct / voice
A：克制是把态度放进陈述句；每段可以有判断，但不必每句都表态（条件：未限定）
B：以第一人称"我"作为叙述与判断主体，是冷静的在场者与评语者，不是抒情者（条件：未限定）
模型理由：f05的机制是把态度嵌入陈述句并控制表态密度（每段可有判断、不必每句表态）；f01的机制是选定第一人称“我”为冷静的在场评语者而非抒情者。前者约束表态的形式与频率，后者约束判断主体与情态，可并存但互不覆盖（f05不要求第一人称，f01不含密度限制），故不等价也无排斥。

## pilot-00 / c0048 / distinct / voice
A：误用提醒：写成口号、宣言、连续反问属距离太近、情绪太外露，需收回修辞；通篇无判断、只有事实罗列属把克制误当信息贫乏，需补回判断（条件：出现口号式/无判断写法时纠正）
B：读者被当作通情达理的熟人，可用"你"称呼、直接发问、请读者猜，但不煽情、不请求共鸣、不铺垫感动（条件：与读者直接交流时）
模型理由：f06是误用纠正：口号/宣言/连续反问属情绪太外露需收回，通篇无判断需补判断，双向校准距离；f04规定与读者交流时的熟人口吻（可用"你"、直接发问、请读者猜）并禁煽情。二者只在克制外露上部分重叠，机制（修辞校准 vs 读者关系设定）与条件（误用出现时 vs 直接交流时）不同，且f04允许发问不等于f06禁止的连续反问，不构成互斥。

## pilot-00 / c0059 / equivalent / rhythm
A：长句推进后用极短句猛然停下作判断或转向，短句是刹车和换挡不是煽情；一段至多停一两次，过多变断句腔（条件：未限定）
B：堆叠之后收一句字数少、语气硬的判断、后果或事实，形成落差；短句尤其放在读者期待长篇解释的位置上（条件：堆叠之后）
模型理由：两者机制同为：铺陈/堆叠之后收一句字数少、语气硬的判断或事实，形成落差（左称刹车换挡，右强调放在读者期待解释处）。方向与条件一致，左的停顿次数限制与右的“收一句”相容，替换不丢主要约束。

## pilot-00 / c0060 / equivalent / rhythm
A：长句推进后用极短句猛然停下作判断或转向，短句是刹车和换挡不是煽情；一段至多停一两次，过多变断句腔（条件：未限定）
B：一段内铺陈若干长句后至少一处短落点；短句密集处要有稍长的句子重新铺开，避免整段像电报（条件：段落内部节奏安排）
模型理由：两者都要求段落内长句铺陈后设短句落点，并限制短句过多（左：至多停一两次、避免断句腔；右：短句密集处须再铺长句、避免电报感），机制、方向与适用范围实质相同，细节互补而不冲突。

## pilot-00 / c0072 / distinct / language
A：论述中间随时插入第一人称短语，分判断类（表明看法归属个人、带保留意味）与谦抑类（自认无知无能、降姿态但不撤回结论）（条件：未限定）
B：插入不宜连续超过两处，否则主干被打散；需要多次补充时改为先列完再统一补充（条件：句中插入时）
模型理由：左规则限定第一人称短语的语义分工（判断类/谦抑类）与可插入位置的自由度（随时插入），右规则限定句中插入的数量密度与超过后的改写办法。二者只在'插入语'话题上重叠，机制分别是内容类型与数量控制，条件也不同（未限定 vs 句中插入），不可互换。

## pilot-00 / c0084 / distinct / information
A：先认可某前提或流行说法，顺其逻辑一路推到结果滑稽、过分或无法收拾之处，再用一句短判断指出荒谬（条件：未限定）
B：动作和荒诞过程铺开写，感受和后果一笔带过；比喻取自日常低微场景，一句即过、不再引申、不承担论证；无合适素材就不比喻，宁可平叙（条件：未限定）
模型理由：f14是先认可再顺推至荒谬并以短判断点破的论证结构；f25是铺写与略写的篇幅分配及比喻的取材与不引申规则。两者都涉及'荒诞'内容但一个管论证推进，一个管详略与比喻使用，机制不同。

## pilot-00 / c0096 / distinct / voice
A：可把作者自己当论述对象，用第三人称式冷静眼光审视过去的自己，说自己的短处同样不带情绪（条件：未限定）
B：以第一人称"我"作为叙述与判断主体，是冷静的在场者与评语者，不是抒情者（条件：未限定）
模型理由：f18讲把自己当论述对象、以第三人称式眼光审视过去的自己并平静承认短处；f01讲谁在说与说什么角色——第一人称'我'作为冷静的在场评语者而非抒情者。两者只是都要求冷静，对象与机制不同（自我描述视角 vs 叙述主体身份），且第一人称叙述者完全可对过去的自己施以第三人称式目光，可并存无排斥。

## pilot-00 / c0108 / distinct / voice
A：自嘲落在可核实的自我评价（资历、能力、处境一类），用具体而短的措辞点破，不用抒情（条件：未限定）
B：读者被当作通情达理的熟人，可用"你"称呼、直接发问、请读者猜，但不煽情、不请求共鸣、不铺垫感动（条件：与读者直接交流时）
模型理由：f19讲自嘲的内容与措辞（可核实、具体而短、不抒情）；f04在与读者直接交流的条件下讲如何称呼和对待读者（用"你"、发问、请读者猜，但不煽情不求共鸣）。一个是自我评价写法，一个是读者关系处理，条件与机制均不同。

## pilot-00 / c0120 / distinct / voice
A：自嘲之后立即转向一般化判断：把个人经历抽成可迁移的观察，避免沉溺自怜（条件：自嘲之后）
B：不直接开骂，不用感叹号加力，不用反问连环轰炸（条件：讥刺时）
模型理由：f20规定自嘲之后的结构动作（立即一般化、避免自怜），f14规定讥刺时的手法禁区（不骂、不用感叹号、不连环反问）。条件与机制均不同，一为转场去向，一为语气工具的禁用，可并存但互不涵盖。

## pilot-00 / c0132 / distinct / language
A：把行为归因于“好的动机”再陈述后果，让动机与效果形成对照；归因句要写得像客观陈述（条件：未限定）
B：插入不宜连续超过两处，否则主干被打散；需要多次补充时改为先列完再统一补充（条件：句中插入时）
模型理由：f23规定动机归因与后果对照的写法；f12规定插入语数量上限与多补充时的布局。一个是内容对照构造，一个是句法插入管理，适用条件也不同（未限定 vs 句中插入时）。

## pilot-00 / c0144 / distinct / constraints
A：具体细节（数字、物件、感官、动作）有则用一两处压实抽象判断，无则省略，靠语序、停顿、照应维持质感；绝不可为“生动”扩编工具、场景或他人反应（条件：未限定）
B：任务给定的事实、必写数量、身份、地点、状态与结果优先于任何风格偏好，必须写全写准（条件：任务给出必写事实时）
模型理由：f27约束具体细节的取舍与禁止为生动扩编，f29约束任务必写事实须写全写准并优先于风格；一个管细节的克制使用，一个管给定事实的完整呈现，机制不同且可并存。

## pilot-00 / c0156 / distinct / ending
A：收尾方向由本篇任务决定，不预设怀念、批评或讽刺的固定落点（条件：未限定）
B：也可以在推论将要展开时主动收住，把话说一半就停（条件：推论将要展开时）
模型理由：f30约束结尾的取向由任务决定、不预设固定落点；f27约束在推论将展开时截断、说一半即停。前者是方向来源，后者是停笔时机与截断手法，适用条件（未限定 vs 推论将展开时）与机制均不同，无反向要求。

## pilot-01 / c0000 / distinct / voice
A：说话人自置于业余位置，先承认不够格甚至预告冒犯内行，然后照样把话说完且说得不软；自嘲只用于降姿态、管理情绪，不用于收回判断，判断保持清晰带锋芒。（条件：未限定）
B：第一人称判断驱动全文，好恶轻重取舍直接说出，判断词常用“我认为”“必须承认”“我相信”等显眼表态标记，读者与作者如当面交谈，不刻意讨好（条件：未限定）
模型理由：左规则是身份姿态机制：开局自置业余、自嘲降姿态但不撤判断，判断带锋芒；右规则是表态标记机制：以第一人称显眼判断词驱动全文、如当面交谈不讨好。二者仅共享“直说判断”的宽泛取向，手段与落点不同，且无排斥。

## pilot-01 / c0012 / distinct / constraints
A：第一人称的判断、反感、自嘲、事后评点可自由使用不需亲历许可；但具体回忆、亲见、亲手操作、现场对白、确切数字仅在任务给出依据时写，无依据时靠语序停顿照应措辞维持声音，不扩编人物动作感官细节。（条件：无任务依据时）
B：句子短不等于段落短；段落是论点单元，一个段落里通常只推进一件事（条件：未限定）
模型理由：f03约束无依据时可写什么（判断自由、具体经验需任务依据、不得编造）；f06约束段落组织（段落是论点单元、一段推进一件事）。机制与适用条件完全不同。

## pilot-01 / c0024 / distinct / rhythm
A：第一拍用中性略带敬意的短篇幅复述通行说法或权威判断，不替对方长篇辩护。（条件：三拍中的第一拍）
B：括号夹注用于交代词语来历或外部知识，紧跟被说明的名词，读完回到主线；括号不写主要判断，判断必须在正文句子里完成（条件：使用括号夹注时）
模型理由：左规则（三拍第一拍）规定开拍内容机制：中性短篇幅复述通行说法或权威判断；右规则（使用括号夹注时）规定括号的语法位置与内容分工：交代词语来历、不写主要判断。一个是段落三拍结构的起拍写法，一个是括号用法，机制与适用条件均不同，也无互斥。

## pilot-01 / c0036 / distinct / information
A：伪量化全篇一到两次即可；任务无数字素材时保留权衡折算比较取舍等动词与相对量说法，不编造具体比值或统计；拆台句要紧跟精确化之后。（条件：任务没有数字与量的素材时）
B：把审美、伦理等抽象判断落到一个门槛很低、略带尴尬的身体经验或日常遭遇上，用“类似”“可以相比”“与此相当”等并置关系连接两件事，分寸留给读者体会；并置后可加一句坦白（承认说法古怪或因此做错），语气随之压低（条件：抽象判断需要具体支撑时）
模型理由：左限定伪量化频次、无数字素材时不编比值、拆台句紧跟精确化；右为抽象判断落到身体经验的并置类比加坦白。一个是伪量化的频次与禁忌条件，一个是具体化支撑的并置机制，不同。

## pilot-01 / c0048 / distinct / language
A：同段并置文雅/学术语域（引述、术语、分项）、口语粗直语域（俚语、粗率形容、市井动词）、技术行话语域，用落差产生幽默和锋芒。（条件：未限定）
B：遇可归类的现象，先起一个口语化、略带滑稽的戏称，再用一两句界定清楚；戏称负责态度，界定负责准确，两者紧贴出现；命名后立刻说明边界或例外（条件：遇可归类的现象时）
模型理由：f14是同段并置三类语域（文雅/学术、口语粗直、技术行话）以落差取幽默与锋芒；f18是遇可归类现象时先起口语化戏称再紧贴界定边界，机制是命名加界定分工。一个是语域并置落差，一个是戏称＋定义结构，仅在口语化和幽默感上部分重叠，条件与作用面不同，无相互排斥。

## pilot-01 / c0060 / distinct / constraints
A：比喻、假设和推论基于已有信息，不得当作发生过的事。（条件：未限定）
B：链条每一步必须字面上顺理成章，滑坡感由接续词连续推进制造；某一步跳得太远会显得硬扣帽子（条件：构造归谬论证时）
模型理由：f17限定比喻、假设、推论不得被当作已发生的事实（本体标注）；f11限定归谬链条每步须字面顺理成章、靠接续词推进、不得跳跃（构造归谬时）。一个管内容的地位标注，一个管推演步骤的连贯性，条件与机制均不同。

## pilot-01 / c0072 / distinct / voice
A：讽刺操作二：平铺直叙地描述过度合规、过度精确、过度讲究的姿态，越冷静越有效；形容词少用，贬抑词体积小、位置靠句尾，语气是调侃不是控诉。（条件：未限定）
B：第一人称判断驱动全文，好恶轻重取舍直接说出，判断词常用“我认为”“必须承认”“我相信”等显眼表态标记，读者与作者如当面交谈，不刻意讨好（条件：未限定）
模型理由：f19是讽刺白描机制：冷静描述过度合规姿态，贬抑词缩小并移至句尾，语气调侃；f01是立场表达机制：以第一人称和显眼判断标记（我认为/必须承认）直接说出好恶。二者一个要求贬抑低调轻放、一个要求判断显眼直说，处理对象不同（被讽刺对象的姿态与作者本人的立场），可并存但机制与手段不同，不等价也无明确互斥。

## pilot-01 / c0084 / distinct / information
A：详略安排：推演、假设延展、针对漏洞的挑剔三处展开写足；背景交代、引述来源来历、场景环境压缩到一句带过，不为营造氛围编场景。（条件：未限定）
B：铺陈同类对象时先并列给出，再逐个一两句点断式简评，简评节奏快、长短不一，不必每项等量展开；详略由判断轻重决定，说得最狠的一项可多留一两句，其余一带而过；列举只是铺垫，重心落在其后的总评或推演上（条件：需要铺陈同类对象时）
模型理由：f22按内容类型分配篇幅（推演等展开、背景来源场景压缩）；f24规定同类对象列举时的详略与节奏（逐项一两句点断简评、详略由判断轻重决定、重心在总评或推演）。两者都提到推演要重，但机制与适用条件不同：一个是全局内容取舍，一个是列举场景的展开方式。

## pilot-01 / c0088 / equivalent / ending
