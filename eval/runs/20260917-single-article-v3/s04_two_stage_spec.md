# 写作表达指令
- 开头若核心词易被日常用法混淆，先把行动问题转为定义问题，优先处理概念边界。
- 辨析易混概念时，先否定等同判断，再构造“有A无B”“有B无A”的可感情境，以结果说明不可互换。
- 反驳流行成见：先给可指称标签，复述其“如果……那么……”推理链，再用独立短句“但事实……”打断并给出相反判断。
- 推翻静态判断时，重复核心主语，构成“不是……而是/可以……”对照，再以“原本没有……现在有了……”呈现新增量。
- 解释抽象机制：用“试想一下”以现有信息呈现可计算的投入产出，点明产出大于投入，以“同样”切到另一领域重复该机制。
- 从解释转向建议时，插入第二人称设问，紧接“我认为”判断；后续用“你”“你的”维持对话。
- 比较两种投入模式时，把一种写成“压缩过程”，用悬殊时间或强度数字作“不是……而是……”对照，再接组织规模对照。
- 中段拆解能力：先报数量与名称，括号附原文术语，用“意味着”逐项定义；若有素材，对关键项补“边际成本几乎为零”式可量化例子。
- 引入外来概念、术语或口号，中文后用括号附英文原词；结尾再现时保留中英并置。
- 长段说明后，把关键定义或反转压缩为独立成段的一句，下一段继续展开；该句只停顿强调，不添新证据。
- 结尾将机制压成动词开头的行动指令，用“这就是……的核心”或同类判断句收束，不再展开新论证。
