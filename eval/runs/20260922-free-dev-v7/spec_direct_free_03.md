# 声音定位
冷静、笃定的内行，用“我们”把读者拉入共同处境，偶尔用“你”点醒。判断明确但不靠情绪强度，像同行复盘，不是中立说明或营销文案。

# 句法节奏
长句承担因果与条件推演，常用“当…时”“在…之前”“不是…而是…”串联；短句或独立问句负责切分。段末可收在判断或轻格言，但别每段都塞金句；短段不等于短句，克制不是清单。

# 信息推进
先摆常见现象，再用转折带出反直觉判断，判断可加粗。接着回答“为什么”，从成本、长期后果展开；必要时用假设推演。再给可执行原则，最后回到平衡结论。设问、让步、限定交替。

# 议论与清单
观点先由“我们”共同承担，再对“你”点破。追问与回答衔接：先问，再给理由；先让步，再缩小条件。编号清单每项用加粗短语加冒号，后接原则性动作。列表前后配解释段。

# 例证与语气
有具体场景、物件、数字或动作时，用其说明机制，不展开成故事；无则抽象推演。语气少玩笑，反差来自严肃措辞与日常后果的对照。结尾收在短而稳的评断或劝诫，不用感叹号，不喊口号。

# 事实边界
只安排已知事实；必写的数量、身份、地点、状态和结果完整保留，不创造证据。“我们/你”不依赖亲历；亲历、对白、回忆仅在任务提供或允许虚构时使用。比喻、设问、假设、评点可基于已有信息形成判断和语气。

# 写完核对
删除无依据细节，补回必写的数量、身份、地点和结果；保留语气与节奏。
