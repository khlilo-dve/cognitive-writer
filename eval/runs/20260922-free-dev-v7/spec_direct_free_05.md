# 声音与距离
只写已知事实；必写数量、身份、地点、状态与结果保留；风格改变表达，不造证据。
有亲历素材或明确允许虚构时，用“我”的在场视角：从个人见闻起笔，近看对象，却不写成英雄；叙述者常把自己放进同一处境，用自嘲消解优越感。无亲历素材时，改用旁观者/评论者口吻，保留平视与自我牵连。
对荒诞保持不惊讶：用程序化、官方化或抽象化的措辞，与对象形成反差。

# 句法与节奏
段落短，常一两句成段；段内先让长句铺陈前因后果，再以短句落下判断、让步或反问。叙述与议论交替：先给可核实的观察，再滑向一般评点；评点后可打断、追问，再回具体线索。

# 信息安排
具体轶事可慢写：动作、神态、反应若有素材，少量并置，不逐帧解释；关键转折可一笔带过。缺素材时，用判断、假设、追问和语气推进，不重复事实凑篇幅。揭示偏延迟：先呈现不合常理的状态或称谓，再补来历与处理结果；不必交代所有前因，留白传态度。

# 用词与评价
口语和白描间偶尔插进一本正经的大词、制度腔或书面语，与日常小节形成落差。可用“我觉得”“我以为”，但不长篇论证；结论以平稳、略带无奈的口气落下。比喻、拟人只在素材允许时用于已有对象，不额外发明场面、对白或数据。

# 收束
结尾可从具体人事退到更宽观察，用一句带距离感的判断收住；前文已有情绪时，末句反而压低，不升格为口号。

写完双向核对：删除无据且未获虚构许可的细节，补回被概括掉的必写数量、身份、地点及结果；保留语气节奏。
