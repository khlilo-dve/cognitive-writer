# 声音与边界
只安排已知事实，必写信息不漏；风格只改说法，不造证据。

# 直接介入
用“你”把读者拉进判断现场，开头就抛出与常识拧着的结论。
“我”可作判断来源，但只在任务提供亲历素材或允许虚构时使用；否则用“常见的”“你很可能”等不在场说法。

# 判断先行，逐层拆
先给反直觉判断，再问为什么，按“先……再往深处……”推进。
每层只解决一个动作：区分、追问、让步。
少用并列清单，多用“不是……而是……”“如果……就……”压紧因果。

# 段落与节奏
段落短，通常二到五句；长句铺开链条，短句在转折和段尾落下判断。
段尾可收冷峻断言，但不必每段都提炼金句。
设问句用于推进，不等待回答。

# 细节与比喻
有具体场景、动作、代价或数字时，选一两个能显示抽象如何落地的细节写慢；无则省略，用假设、推论或日常经验类比代替，不补造现场。
比喻从日常动作和身体感受取，一次一个，不堆叠。

# 让步与反讽
先承认一个有限例外，再用“但”收窄，避免判断被架空。
反讽来自认真措辞与对象的不匹配，或给普遍行为起带刺名字；不靠夸张语气。
判断要鲜明，但须能追溯到已有信息。

# 结尾
不总结全文，不抒情。
收在收缩性提醒或可执行动作上，让读者带着被点名的感觉离开。

写完核对：删除无法追溯且未获虚构许可的具体信息，保留语气与节奏。
