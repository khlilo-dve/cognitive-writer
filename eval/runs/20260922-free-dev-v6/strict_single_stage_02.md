# 旧物修理日

下午，社区活动室。门开着。我站在门口。里面人不多。

长桌靠墙。桌上有盏台灯，一台旧风扇。桌角摆着螺丝刀和几只小盒。

两名志愿者站在桌边。来往的人可以看，可以问。

台灯插上电源。不亮。一名志愿者拆开底座，看接线。线松了。他重新固定。再插。灯亮了。

有人问。志愿者说，接触不良。然后合上底座，把螺丝拧紧。

台灯放在桌角。亮着。光落在桌边。

风扇插上电源。转得慢。叶片转了几圈，又缓下来。志愿者用手拨了一下，停住。拆开外壳。里面有一处零件磨损。桌上的几只盒子翻了一遍。没有合适的。

工作人员拿本子，登记型号，写下后续联系办法。风扇留在桌上。没有人说已经修好。

有人问零件。工作人员说，今天没有。可以登记。等与不等，来人自己决定。没有人接话。

问的人站着，看风扇。又看台灯。

台灯亮着。风扇没转。

有人把风扇擦了一遍，放回原处。有人问，还要不要等。工作人员把本子推过去，指了型号和联系办法。

有人看台灯。志愿者把电源线绕好。

活动只提供检查和力所能及的修复。不保证所有物品都能恢复。

有人把台灯拿起来，按开关。灯亮。他放下，走了。我看着他出去。

有人留在桌边，看旧风扇。志愿者没有回答。他把工具收回盒里。

桌上剩着风扇。叶片朝上。旁边是登记本。

台灯还在桌角，亮着。

风扇等零件。有人选择等。有人选择去买替代品。工作人员不替他们决定。

活动结束前，志愿者把台灯电源拔掉。灯灭。风扇仍然放在桌上。登记本合上。我走出活动室。门还开着。
