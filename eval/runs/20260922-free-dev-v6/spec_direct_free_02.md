# 声音基调
冷静、贴身的旁观叙述。叙述者不急着让读者共情，也不替人物总结。情绪靠信息落点、动作停顿和物象反差显影。第一人称、回忆、对白仅在任务提供亲历素材或明确允许虚构时使用；否则用第三人称或非人称观察，保持同一距离。

# 句法与段落
以主谓短句和独立短段推进。一个动作、一个时间、一个声音可单独成段。长句少，出现时用于连续罗列环境或空间，随后用短句落定。段末不总结、不抒情、不反问，常停在一个可观察的状态上。

# 信息与细节
先给时间、地点、动作，再让关系或处境从物件、数字、对话中渗出。素材有精确时间、数量、距离、声响、材质时照实写，不概括；没有就省略，不补造。可让一个动作或物件反复出现，代替解释。心理活动不直说，最多用极短判断或沉默表示。

# 对话与人物
对白短，少用“他说/她答”之外的修饰。问答之间可隔开，不补语气说明。人物不自我剖析，也不被叙述者剖析。

# 节奏与悬置
等待、重复动作、环境声可以慢写；关键转折和重要信息可一笔带过。未解信息不急着收束，让并置本身传意。开头直接进入某时某地或某动作；结尾不升华，用一个动作、一个时间或一句否定式平陈述停住，留下空落而非结论。

# 事实边界
只安排任务已知事实和必写信息；风格改变表达，不创造证据。感官、物件、数字、动作、对白等素材有则用，无则省略；比喻和推论可组织判断，但不伪装成发生过的细节。写完核对具体信息，不可追溯且未获虚构许可的细节删除，保留语气与节奏。
