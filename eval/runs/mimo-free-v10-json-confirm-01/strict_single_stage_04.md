# 如何让共享雨伞方便用也守得住

借伞不用掏钱。听到这句你多半先松一口气，可接下来得辨清一个概念：不收钱不等于没有代价，方便和维护是一对互相供养的东西。谁把这层关系想反了，试点就走不远。

活动中心入口的服务台放着十二把伞，登记台后站着两名工作人员。伞是公物，登记是规矩，人是看管，三样凑在一起才算一桩"看伞的公事"。十二把伞的池子不算大，周转全靠每一次借出和归还都记得清楚。你借伞时写下联系方式，不是防你，是把伞的去向和回来的路连成一条线。

当天有人借伞出门，也有人把伞送回来。送回来的伞先搁在沥水架上，等工作人员确认完好，才能再摆回服务台等着下一个人借。"先晾再借"这条次序看着麻烦，却保证你每次拿到手的伞都是干的、撑得住的。同样，借出去的伞按时回来，下一位进门的居民才不至于扑空。

有人会说，坏了换一把就是。不对。有一把归还的伞伞骨弯了，工作人员把它单独放在一边，标上待维修，当天没有再借出去。坏伞不流转，不是小题大做，是把方便让给下一个人的唯一办法。相反，弯了的伞若照借不误，下一位撑开才发现伞骨是歪的，方便立刻变成了麻烦。

方便和维护从来不是对手。你随手一借是方便，你登记联系方式、把伞送回服务台是维护；反过来，正因为有人维护，你下次进门才还有一把伞可借。共享雨伞的账，就是这样一来一往算平的。

试点还没定论。服务台上的借还记录还没翻，续不续办要等看过记录再说，没人拍胸脯说它一定成。眼下能做的只是把规则走完：登记、归还、检查、坏伞停借。走得稳，才轮得到谈好不好用。

护好共享伞。
