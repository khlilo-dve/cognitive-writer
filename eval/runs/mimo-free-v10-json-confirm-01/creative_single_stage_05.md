# 共享雨伞站的"老友记"，一共十二把

虚构场景。以下都是我在活动中心门口看到的。

十二把共享雨伞站在入口的架子上，本来各淋各的雨，各躲各的晴，谁也不欠谁。编号也是没有的，谁离门近谁先被拿。然后两名工作人员来了，一人管册子，一人管伞架，配合得像老搭档，摆好登记册，请大家留下联系方式。

我给其中一把起了名字，叫阿骨。他骨架宽，脾气拗，被借走的时候从不肯利落地合拢，得人使劲儿勒。要登记、要写电话、要说清楚几时还，我有点想笑，一把伞而已，办得像办信用卡。工作人员倒是认真，一笔一划，还问一句：住哪栋？我说我是来看热闹的，他们还是让我签了名。

有人借伞出门，也有人回来还。还不上的先上沥水架，滴干净了，检查完好，才重新排进可借的行列。伞面破了口的、握把松了的，都得在册子上记一笔。阿骨回来时伞骨弯了一截。

工作人员把他从队伍里拎出来，单独立在角落，贴了张纸：待维修，暂停借出。他那天再没被借出过。我把伞还回去时填完单子，心想办张纸卡都没这么费劲。

人好像天生就爱给别人安排点什么。伞顺性而活时没人管，一进共同维护的框子，就要排队、沥水、等检查，连站姿都有了讲究。这规矩放进任何一个楼道、任何一间办公室，都长得一模一样。可要是不维护，谁来撑下一场雨？方便和干净，从来不是一个人的事。

阿骨不算好伞。他会挂坏你的袖口，会在收伞时戳到旁人，可他撑得最稳，风大的时候别的伞翻过去，他只是弯一弯腰。他大概是十二把里最不肯被安排的那一个。坏伞不是完伞，这没什么好洗的。

试点没有宣称一定成功。借还记录会摊开来，看完再决定续不续，谁也没说这十二把伞能站多久。我如今在别处打工，下雨天没人陪我等雨停了。
