# 待维修的那位

活动中心入口摆着一张服务台，台后是两名工作人员，台边立着十二把伞。伞平常挤在架子上，滴水不沾，一副与天气无关、与人无关的样子。

后来有人给它们安排了差事：借伞不收费，登记联系方式即可，居民来了撑一把走，雨停了再送回来。一套挺好的服务，落到十二把伞头上，就成了流水的活儿。

我也说不清为什么，总觉得这差事来得顺理成章，好像伞天生就该出门。我这想法多半是一厢情愿。

台子虽小，规矩一样不少：借出要登记，归还要检查，坏了要停借。

伞回来先上沥水架，等水控干，工作人员再逐把查看，确认完好，才重新列入可借。这一步没人省。省了，就不叫共享，叫凑合。

偏偏有一位不争气。伞骨弯了，被单独拎出来，搁在角落，贴上"待维修"。当天它没有重新借出，没人替它说情，也没人把它扔回架子充数。十一把照常流转，它自己待着。

两位工作人员，十二把伞，数目不对等，全靠规矩补。

人使东西，只图顺手；东西想活得久，就得有人肯停下来，把弯的那把挑出来。方便是当场兑现的，维护是往后拖的账，账总要有人记。十二把伞能天天借出去，靠的不是运气，是有人把好借出的和不该借出的分开。少了哪一条，十二把伞撑不过几场雨。

登记也是一样。一行联系方式，看着麻烦，既是找伞的线索，也是共同维护的起点——伞不是谁的，可总得有人认账。试点结束后要翻借还记录，再决定要不要继续。没有人提前宣布一定成功，这话说起来平淡，比伞骨还结实。

如今许多地方只学了前半截：先图方便，再商量维护，商量到后来也就没了下文。活动中心门口这一小摊，把两截都摆在台面上。

雨停之后，那把伞还待在角落，等一个说法。我记得那种被搁下的安静。
