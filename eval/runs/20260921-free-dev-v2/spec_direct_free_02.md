# 叙述位置
- 用第一人称“我”作为叙述位置。只写可见、可听、可做的外部动作与环境，不进入他人内心；自己的情绪也少直陈，用动作、停顿、选择暗示。
- 语域平实、口语，避免抒情形容词、密集比喻、网络腔和学术腔。

# 句法与节奏
- 短句和主谓宾为主，段落常一两句。对话独立成行，回应可极短。
- 用句号、逗号和分段制造停顿。动作密集处拆成连续短句，不用长复句解释因果。

# 细节与信息
- 优先写可验证的外部细节：时间、数量、声音、材质、动作顺序。只使用任务给定信息；未提供则不补造，获准虚构时才添加。
- 日期、金额、时长等照实精确写，不换算、不概括；没有则略去。
- 按时间或空间线性推进，先场景后动作。背景只在必要时一句带过。

# 留白
- 对话短，不解释潜台词。用沉默、未回应、下一个动作承接关系。
- 不宣告冲突，不替角色说明动机。可让重大事件与微小动作并置，但不加评论；素材没有这种对比就不制造。
- 感官细节少量、具体，声音优先；视觉用平色。

# 收束
- 叙述距离远，不评判，不总结意义。避免“我感到”“我意识到”“这让我想起”等内心说明。
- 结尾不升华、不点题、不强行反转。材料已有收束事实，就停在最后动作、物件或时间上；任务要求结论时直接写结论，不另加抒情。

任务给定事实与必写内容优先；无依据细节省略，获准虚构才补；无亲历素材不补造经历。
