# 那盏灯亮了，风扇还在等零件

虚构场景。

我们这片的社区活动室，每月有一次旧物修理日。平时门关着，里面堆桌椅和杂物；那天门开着，像谁忘了合上的嘴。我路过，就进去了。

桌上两样东西：一盏绿罩台灯，一台风扇。

台灯线在底座附近拧成一团。风扇叶片积灰，按开关，转得像个不愿起床的人。

两名志愿者。一个戴眼镜，一个穿工装背心。他们不急着动手，先看，再问。

“怎么坏的？”

“碰一下就灭。”台灯主人说，“有时拍两下又亮。”

这话我熟。我家以前也有那么一盏。拍两下，亮；再拍，灭。后来我把它扔了，买新的。不是不能修，是当时觉得，修的时间够买三盏。

志愿者翻过台灯，拆底座。接线松了，铜丝露着，像一句没说完的话。重新固定，缠胶布，插电。

灯亮。不闪。稳稳亮着。

有人“哦”了一声。台灯主人也“哦”，比志愿者还轻。

风扇没这么顺。拆外壳，摇头，说轴承磨损，得换零件。当天没带。

“能修吗？”

“能修，但要等。”

“等多久？”

“登记型号，联系到了通知。”

工作人员在本子上写型号、规格、电话。写完合上本子，没说“修好了”。

我在旁边看着，觉得这个“没说”很要紧。

有人问志愿者：“为什么不干脆劝人买新的？”

戴眼镜的想了想：“有些东西，买新的更省事。但省事不是唯一的标准。”

穿工装背心的补一句：“我们只做能做的。做不了的，登记，不吹牛。”

这话平淡，我却站了一会儿。

台灯主人抱灯走了。风扇主人留下电话，也走了。桌上空一块，剩一圈灰印。

我想起那盏被我扔掉的灯。它大概在某个填埋场，或者早散了。当时没觉得可惜，只觉得方便。

修理日不保证什么。只提供检查和力所能及的修复。有人在乎原物继续用，有人在乎时间，有人在乎钱，有人只是路过看看。

都对。

只是那风扇还在等零件。等得到，就转；等不到，也许被换掉。

灯已经亮了。风扇还没。

出门时回头，活动室灯管有一根在闪，没人修。
