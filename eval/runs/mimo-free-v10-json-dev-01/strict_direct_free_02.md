# 修理日

社区活动室里摆开一张长桌。桌上两件旧物。一盏台灯，一台旧风扇。旧物摆在那里，等人来看。

台灯接触不良。开关按下，亮与不亮都可能。灯还能用，用起来不安稳。

风扇转动缓慢。扇叶还在转，转得慢。慢下来的风扇，也算一件难题。

两名志愿者负责检查。两件旧物，一人看一件。来访者可以旁观，可以提问。桌边站着人。有人看志愿者的手，有人看桌上的旧物。问一句，答一句。手上的活不停。

台灯先上手。外壳卸开，接线露出来。接线松动。毛病就在这里。志愿者重新固定接线。外壳装回去。开关按下，灯亮。亮与不亮的毛病没了。台灯恢复正常。

风扇接着看。问题在零件。要换零件，风扇才能恢复。当天没有合适的零件。拆开检查完，装回原样。工作人员登记零件型号，写下后续联系办法。零件有了，再联系。风扇没有被说成修好。没有人宣称它已经修好。它只是被登记了。

活动的边界摆在明处。只提供检查和力所能及的修复。不保证所有物品都能恢复。接线松了就固定，零件缺了就登记。这叫力所能及。修得好的当场修。修不好的登记型号和联系办法，等零件。

桌边的人看重的东西不一样。有人重视继续使用原物。修好就接着用，原物不必换。有人更在意等待和购买替代品之间的取舍。等零件，原物还在，人要多等一段。买替代品，眼下就有得用，原来那台就不用再修。等要时间。换要多一台新的。

修好与没修好摆在同一张桌上。修理留住原来那台，付出的是等待。替换省下等待，原来那台就退出使用。有人看台灯，有人看登记单。

台上留下两样结果。台灯亮着。风扇的型号写在登记本上。
