# 为什么修好的是台灯，不是风扇？

旧话讲，旧的不去，新的不来。

**但修理不是让旧物永远不出事，是让它今天还能亮。**

社区活动室的桌上摆着两样东西：一盏接触不良的台灯，一台转得慢的旧风扇。两名志愿者俯身检查，围在桌边的人看着，也开口问：这还有救吗？

先说台灯。接线松了，志愿者把线重新固定。灯亮了。

**第一道门槛，是拧紧一处松动。**

不用买材料，不用等。它拦不住谁。

风扇是另一回事。它需要换零件，当天桌上没有合适的型号。工作人员记下零件型号和后续联系的办法，没说它已经修好。

**第二道门槛，是等一个零件。**

价钱还在后面，时间先押了进去。它开始筛人。愿意押时间的人，才走得完这一步。

**修不好的，不该被说成修好了。**

这就是修理的边界：只做检查和力所能及的修复，不保证每样东西都能恢复。

旁观的人问得最多的，正是这一句：为什么它不能也修好？看清接线和看清零件，不是同一件事。一个今天就能收工，一个只能往后推。门槛不同，就不能用同一句话下结论。

留下的零件型号和联系办法，是把没办完的事交到以后，而不是交到运气上。

那你还修它做什么？有人要继续用原物，舍不得它被换掉。有人在意等待和掏钱买替代品之间，哪个更划算。

你舍不得的成立，但它只在零件还在、等待不长的地方成立。一旦零件型号难寻，等待本身就是价钱，只是没写在小票上。

你舍不得那台风扇继续转，也舍不得为它多等一阵子。这两样舍不得，只能挑一样。

台灯是拧一下就能继续用的账，风扇是要押上时间去等的账。**两张账，不能用同一句话算。**

下次走进修理日，先问志愿者一句：是拧紧就好，还是要等零件？

**问出这一句，你就不会把等待当成免费。**
