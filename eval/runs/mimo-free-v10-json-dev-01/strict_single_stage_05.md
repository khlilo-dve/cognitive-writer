# 暂不痊愈的旧风扇

社区活动室的桌上摆着两件旧物：一盏接触不良的台灯，一台转动缓慢的旧风扇。

它们不说话，只是摆在那儿。一个亮不了，一个转不快，各有各的毛病，倒也算门当户对。

检查它们的是两名志愿者。流程朴素：先看，能修就修，修不了就登记。这规矩没写在墙上，桌面的情形就这么运转。

我在一旁看着，站的位置有些尴尬。修与不修的分寸，轮不到旁观的人插嘴。

台灯的病小。接线松了，志愿者重新固定，灯就亮了。过程短得近乎敷衍，我看得有点不好意思，像是白捡了一件好事。

围观的人可以提问，也确实在问。问题落在两处：一处是还有没有救，一处是值不值得救。

志愿者答得克制，只说到检查和力所能及的修复为止，不保证每件都能恢复。

边界画在这里，谁也没有被得罪。

他们用的词很朴素：检查，力所能及，不保证每件都恢复。这些词平日听来像公文，落在两件旧物身上，倒还算体面。

风扇那边麻烦一些。它能转，只是慢。拆开看过，需要换零件，当天没有合适的。工作人员便把零件型号和后续联系办法记下来，没有宣称它已经修好。

“修好”两个字，今天不归它。

于是取舍浮上来。在场的人里，有的更看重原物继续用下去，哪怕慢一点、旧一点；有的更在意等待与购买替代品之间怎么权衡。

两种心思各占一头，谁也说服不了谁，最后各自收回目光。

若替它们算一笔账（这里只是打个比方）：等几天要等，掏钱换新要掏，两头都不空着手。

修理这活计最诚实的地方，是不许诺结局。台灯亮了，风扇没有；一件被带回生活里接着用，一件留在登记上，等人再来认领。

活动散的时候，台灯是亮着走的。

风扇没走，它只是被写进了一行字里。我站在人群后头，觉得那天的活动室很安静，安静得像一句没说完的话。
