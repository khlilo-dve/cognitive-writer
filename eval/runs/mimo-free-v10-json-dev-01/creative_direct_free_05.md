# 旧物修理日

*虚构场景*

社区活动室的长桌上摆着两件东西，一盏台灯，一台旧风扇。它们本来各自待着，一盏不亮，一台转得慢。人来了，事情才开始。两名志愿者坐在桌后，一人管接线，一人管拆机，面前摆着登记本、螺丝刀和一小盒保险丝。我估计那盒保险丝一天没用上。

台灯的毛病最小。接触不良，灯忽明忽暗，像故意的。台灯的主人站在旁边，不吭声。志愿者把底座拆开，看见接线松了。他重新拧紧，合上盖子，插电，灯就稳了。前后不到十分钟。主人这才开口，说这灯是搬家时带过来的。旁观的人说，这么简单，我自己也能修。志愿者点头说，是简单。

风扇就麻烦些。转得慢，叶片有声，像喘不上气。风扇的主人问，今天能好吗。另一名志愿者拆开外壳，看了轴承，说要换零件。当场没有合适的。他把零件型号抄在登记本上，又写下一个电话，说零件到了会通知。没有一个字宣称已经修好。这一点我以为是对的。修不好就说修不好，省得日后扯皮。

问的人不少。有人问能不能修电饭锅，有人问旧椅子值不值得修。志愿者只答自己能答的，答不了的就摇头。规则写在门口的纸上：只提供检查和力所能及的修复，不保证全部恢复。白纸黑字，公文腔，读起来倒也顺眼。登记本翻过去几页，有些栏是空的。

争论出在修理与替换之间。一个说，原物用惯了，坏了也想留。另一个说，等零件的时间够买台新的了。两边都没错，看你要的是什么。有的人图的是那盏灯陪过的那些年，有的人算的是这周还热不热。零件要等，人也要等，等不等全看自己。我以为风扇的主人属于前者，他登记完还站了一会儿。

台灯亮着，风扇登记着。一件修好了，一件没修好，都没什么好说的。活动室关门的时候，桌上只剩那张登记单。
