# 旧物修理日

社区活动室，一张桌子，两件旧物。一盏台灯，接触不良，亮一下，灭一下，像说话打磕巴；一台旧风扇，转动缓慢，扇叶还肯动，只是不着急。没人碰它们的时候，它们就是这副样子，毛病摆在明处，谁看都看得出来。两件东西并排放着，像两位候诊的老人，谁也不替谁说话。

活动的规矩先摆在前面：只提供检查和力所能及的修复，不保证所有物品都能恢复。这话听着客气，其实是实话。两名志愿者负责检查，来访者可以旁观，可以提问。没人承诺过什么，事情反倒好办。

台灯先看。志愿者把它挪到手边，顺着线摸到接口的位置。接线松了。就这么点事。

要动手了。重新固定接线，一圈一圈收紧，手不快，但准。灯恢复正常，亮得稳稳当当。前后一比，就那么一根线的事，一盏灯的命。

风扇没这么省心。它转得慢，要换零件，当天没有合适的。转得慢的还是转得慢，谁也没法当场把它变快。

工作人员把零件型号记下来，连同后续联系的办法一并登记。没说已经修好，也没说哪天修好。登记表就是登记表，不替结果打包票。联系方式留着，事情就没断线。

来访者围在桌边看，想问就问。志愿者答得实在，能动手的当场动手，动不了的就说动不了。一问一答下来，边界反而清楚了：这里是修理，不是包好。

有人更愿意把原物接着用下去，等一等也算不得什么。有人在等待和购买替代品之间掂量：等，要花时间，还不知道等多久；买，当下就有得用，只是到手的不是原来那件。我估计两种心思都算得实在，无非一边把时间花在前头，一边把钱花在前头。等零件的，拿时间换旧物余下的用处；买替代的，拿钱把时间买回来。同一笔账，记法不同。我以为，肯为一件旧物多花心思的人，图的未必是省钱。

那天散场，灯亮着，风扇的事写在纸上。一张桌子，两样交代。
