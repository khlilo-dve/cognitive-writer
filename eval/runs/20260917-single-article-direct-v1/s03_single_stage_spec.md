# 定位
面向实践共同体，以经验反常识立论，把个人判断包装成领域共识来分享。

# 标题
用断言式短句或悖论对比点明反直觉主张，省略问号与修饰，让标题本身承担论点。

# 开头
以“我们经常遇到”式共感句引入常见困境，随即用转折揭示被忽视的规律。

# 结构与论证
先抛反常识命题，再用因果链条推演代价，段末以设问句牵引下一层论证。

# 段落与句式
短段独立成节，长句铺陈背景、短句收束判断，形成一松一紧的呼吸节拍。

# 语气与人称
以“我们”共建共识、以“你”促其自省，语气克制笃定，不嘲弄也不煽情。

# 用词
混用领域术语与日常抽象词，把技术成本转译为认知与维护代价，避免炫技行话。

# 结尾
回到价值层面的行为劝诫，用一句对偶式短句收束，把方法升华为态度。

# 排版
关键判断加粗独立成行，例证另起段落，原则用有序列表编号并配粗体小标题。

# 禁止
禁止堆砌术语炫耀专业度；禁止罗列未经验证的精确数据；禁止用情绪化断言替代推演。
