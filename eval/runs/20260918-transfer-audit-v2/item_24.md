# 修好与未修好之间

我们总以为旧物坏了，修与换只是效率问题。但当你把一盏接触不良的台灯、一台转动缓慢的旧风扇放到社区活动室的桌上，判断就不再抽象。你需要看接线、看零件，也看自己愿意等多久。

**但修理日真正检验的，是边界内可信的下一步，而非救回每一件旧物。**

为什么？

首先，台灯与风扇代表两种相反趋势：一个靠重新固定松动接线即可恢复，一个缺少合适零件而只能登记型号和后续联系办法。其次，当你把焦点从“今天修好几件”移到“之后能否继续使用”，实际约束就出现：零件是否合适、等待是否值得、购买替代品是否更省事。若忽视这些约束，就会把检查变成空头承诺，把未修好说成已解决。

看那盏台灯。检查后发现接线松动，志愿者重新固定接线，灯恢复。代价是检查与动手，但不必替换。再看旧风扇。转动缓慢，需要更换零件，当天没有合适零件；工作人员登记零件型号和后续联系办法，没有宣称已经修好。前后状态没有伪装成同一结果。来访者可以旁观并提问，修复边界因此可见：活动只提供检查和力所能及的修复，不保证所有物品都能恢复。

有人重视继续使用原物，有人更在意等待与购买替代品之间的取舍。这里没有唯一答案。

1. **先查**：先检查，再判断能否当场修复。
2. **明界**：明确只提供检查和力所能及的修复。
3. **如实**：未修好时，登记型号与后续联系办法，不宣称已经修好。
4. **勿诺**：若没有合适零件，不要承诺当天恢复。

我们当然希望每件旧物都留下，但纯粹理想不能替代实际条件；目标应转为在继续使用、等待零件与购买替代品之间动态权衡。

尊重边界，说明后续；衡量等待，再决定替换。这比随口说“修好了”更难，也比直接劝人买新的更诚实。
