# 修不好的那台风扇，才是修理日的底线

东西坏了，第一反应是换。修理日像是在跟这个反应较劲。

便宜的东西坏了就换，修理是情怀，不是现实。

**我偏要说，社区修理日的价值，不在它修好了什么，而在它敢于承认修不好什么。**

为什么承认修不好比修好更难？因为修好是成绩，可以拍照、可以鼓掌；修不好是挫败，容易被当成活动办得不圆满。

可你看活动室那张桌子。那盏台灯接触不良，志愿者检查后把松动的接线重新固定，灯亮了。旁边那台旧风扇转得慢，检查下来要换零件，当天没有合适的。工作人员登记了型号和后续联系办法，没有说“已经修好”。

如果只看台灯，修理日像一场小型胜利。但你若没有看见风扇被登记型号、被记下后续联系办法、没有被称为“已修好”，你可能会以为修理就是万能。

台灯是低成本满足：拧紧接线，光就回来。风扇是高成本行动：承认缺件，等待替换，把取舍交给物主——是等，还是买新的。

等待替换件，和立刻买一台新的，是两种时间账。前者要等，后者要花钱。修理日不替人算这笔账。

“不保证所有物品都能恢复”，这句话写在活动的边界里，也写在修理与替换的取舍之间。有人重视继续用原物，有人更在意等待与购买替代品之间的权衡。

你要是站在桌边看，会发现旁观的人凑近看接线头，问题一个接一个，志愿者边检查边解释。这不是表演，是把判断过程摊开。

**修好是结果，登记是态度。**

修理日不承诺复活一切。

我承认，不是每件旧物都值得等。但当“不保证”被坦然说出口，修理就不再只是技术活，而是一种克制的选择：能修则修，不能修就诚实登记，把替换的决定权还给使用的人。

减去那些“包修好”的幻觉，修理日才真正立得住。
