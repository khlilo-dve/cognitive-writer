# 修理日的边界（虚构场景）

虚构场景。我们总在旧物坏掉时面对同一道题：修，还是换？你低头看那盏接触不良的台灯，或那台转动缓慢的风扇，手指已经滑向外卖与下单。**但修理日真正检验的不是手艺，而是我们是否愿意承认边界，并在边界内继续使用。**

为什么？

首先，社区活动室的长桌上摆着两种相反趋势：有人重视继续使用原物，有人更在意等待与购买替代品之间的取舍。其次，当修复能力有限时，真正决定体验的，是等待与替换之间的权衡，而非当天修好几件。若只追求修好数量，不仅未建立信任，反而让缺件登记像推脱。

看一处对比。台灯这边，志愿者小林发现接线松动，重新固定，灯亮了；你刚才还准备下单同款，现在把手机放回口袋。风扇那边，零件不匹配，工作人员只登记型号和后续联系办法，没有宣称已经修好；你若硬要当天带走，只会把等待伪装成完成。

旁观者问：“今天能修好吗？”回答是：活动只做检查和力所能及的修复，不保证所有物品恢复。旁观者提问，不是打扰，而是把隐形成本摊开。你越早承认修不好，越能保住信任。当零件缺失，边界不是失败，而是下一次联系的起点。

1. **先检**：把“能不能修”与“值不值得修”分开问。
2. **后登**：缺件时登记型号、联系办法，并明确未修好。
3. **若等**：只有当等待成本低于替换收益时，才建议保留原物；没有合适零件时，禁止用“已修好”安抚来访者。
4. **再问**：让旁观者提问，把修复边界说清。

我们当然希望每件旧物复活，但纯粹修复理想并不现实；目标应转为在时间、零件与需求之间动态权衡。留下判断，记下边界。这比直接替换更难，却比假装修好更诚实。
