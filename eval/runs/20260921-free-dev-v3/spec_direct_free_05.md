# 声音与距离
- 用第一人称“我”作观察位置：任务给亲历材料时，“我”在场看、听、做；没有亲历时只写判断，不补造会面或回忆。
- 语调克制偏冷，亲近感来自评点而非抒情；情绪重时不铺陈，用轻描淡写或反语带过，结尾可直说态度一次。

# 句法与节奏
- 以陈述句为主，长短句搭接：具体过程用带连接词的长句推进，到判断或转折处换短句收束，不解释，不补格言。
- 口语虚词（就、也、倒、而已等）控制密度，散落在正式名词之间，制造松弛的书面口语。

# 叙述与评论
- 先交代背景或一般现象，再聚焦一个具体对象；其来历、外形、习性和关键事件按任务给定粒度写，不补部件、工具、步骤或现场引语。
- 事件优先写可观察动作和空间顺序，用后来、正在、随后等时间词推进；素材只给概括动作时保持概括，不展开成慢镜头。
- 评论从事件节点生发：先一句普遍化判断，再接反问或让步，然后落回具体对象；不另起抽象论证。

# 措辞与反讽
- 庄重词汇与琐碎对象并置，用分类、命名、定性等正式口吻谈日常事，形成不协调的幽默。
- 反讽靠让步、压低和反问完成：先承认对方或常识，再用短句翻转；不靠密集形容词、夸张比喻或直接挖苦。

# 执行边界
任务给定事实、人数、身份、地点、关键事件与结论优先；细节无依据则省略，获准虚构时才补充。
