# 修好一盏灯，风扇还留在桌上

东西坏了，按惯性，先想换。

我也差不多。灯闪两下，手指已经点开购物页面；风扇转得慢，心里先盘算新的要多少钱。后来社区办旧物修理日，地点在活动室。我进去，站在桌边看。

桌上摆着两样：一盏接触不良的台灯，一台转得慢的旧风扇。

志愿者两人，负责检查。先看，再拆。台灯毛病不复杂，接线松了。重新固定，灯亮。桌面白了一小块。

风扇没那么顺。拆开看过，零件不对。当天没有合适的。工作人员登记型号，留下后续联系办法，等以后再说。

他们没有说已经修好。

这点让我在意。修好就是修好，没修好就是没修好。登记型号不算修复，只是把等待写进一张纸里。纸上的东西会不会变成零件，谁也说不准。

旁边有人看，也有人提问。问的多是还能不能修、值不值得等。能修的修，不能修的登记。活动只提供检查和力所能及的修复，不保证所有物品都能恢复。

“不保证”听着冷，其实是把话说在前面。

这句话不响亮，但算数。边界摆在那里，不是为了让人失望，只是不想让人误会。

于是桌上有了两种结果：一盏继续亮的灯，一台仍然慢的风扇。

台灯原本只是线松了，风扇原本只是缺个小东西。两样都不大，偏偏一个当场能好，一个不能。等零件这件事，本身也算一种修法，只是慢。

对有些人来说，修好的意义在于原来的东西还能是原来的东西，用顺手了，就不想换。对另一些人来说，问题在于等，还是买。等要花时间，买要花钱，两样都不便宜。

等，未必等得到；买，倒是马上有。可马上有的，未必比手里这台更合意。

我说不清哪种更划算，也说不清自己算哪一种。

修理日并不解决什么，它只是把问题拆开，看看里面还剩什么。有的还剩一根松了的线，有的只剩一张写着型号的纸。

灯亮着，风扇还留在桌上。两件事都是真的。
