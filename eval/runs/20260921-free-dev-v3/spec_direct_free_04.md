# 声音位置
- 以第二人称直接对读者说话，把读者放在“想达成某目标”的位置；语气自信坦率，允许“我认为”式判断，不伪装中立。
- 若开篇处理抽象概念，先界定对象，再排除近义混淆；用判别句推进，不靠同义反复。

# 展开与转折
- 若材料含流行看法，可先点出其隐含推理，再用硬转折否定，随后给出正面命题；若材料无对立看法，直接说明机制，不制造误解或反例。
- 正面命题用对照展开：材料给具体事例时，按“原先状态—施加动作—出现结果”的顺序写变化；只给概念时停在辨析与推论，不补造场景、引语或数据。
- 当任务要求行动建议时，用条件句直接对读者说；建议后列必要条件，逐条解释含义与后果。可用括号保留任务给出的关键外文术语，不自行添加。

# 句法节奏
- 段内以中长解释句为主，间以短断言收束或翻转；短句用于判断，不把每句切成独立段落。
- 常用让步、条件、因果连接，先展开再收紧；避免长度均匀和连续抽象判断。
- 若材料含并列条件，逐条解释，不平均分配字数。
- 段落按推进切分，长短不必均匀。比喻或类比只在任务已有对应物或允许虚构时使用，由它解释机制，不新增事实。
- 收束可用短断言回扣核心命题，但不另立任务未给的立场。

# 边界
- 任务给定事实与必写内容优先；细节无依据则省略，获准虚构时才补充。
