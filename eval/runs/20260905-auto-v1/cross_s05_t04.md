# 一份跟不上引擎的懒人名单

有天下午，我站在同事工位后面，看他输入一句话，等了三秒，对屏幕说了声“不准”，关掉页面，回头给老板发消息：“这个工具还不行。”整套动作流畅得像排练过，关掉页面的那一下，甚至带着一点斩钉截铁的痛快。

后来公司里人人都谈替代，我才知道那一刻不是孤例。模型每次只抽走一小段内容：查资料，顺逻辑，起草稿。可许多人一整天的工作，恰恰就是这一小段。内容在机器眼里越短，坐在工位上的人越显得多余。多出来的人，大多是等着别人把任务嚼碎了喂到嘴边的那一批。

这一批人手里有张很好用的牌，叫“工具不行”。让模型起草，他说不准；让他自己起草，他说没学过。工具不行，成了通行的遮羞布。可有一批人不在布底下。

这批人，是单位时间产出最高的那类。他们不解释自己的工作方式，我能做的只有观察。观察了很久，结论是他们既不爱谈AI替代，也不爱骂AI弱智。别人把模型捧成神，把模型贬成废物，他们听着，不接话，重新把手放回键盘上。

以下谈到的老周，是这批人里的样本。他是前抄表员，以前挨家挨户查水表，后来水表自动远传，他那一排工位被系统收编，便转去替老板写标书。这行当的转折有点陡，可他不觉得。抄表员的习惯还在：看读数，不迷信仪表。他面对模型也是这个态度，先问它要几版草稿，再自己挑。

他亲口讲过操作方法：“写框架，拆任务，批量跑草稿，自己选方向。”工作日志对得上：过去一小时写一版方案，现在一小时能审十版方向。十版里不是每版都能用，但他只要从里面挑一个合用的，再按自己的方向焐热。上个月老周加薪了，加得老板很情愿。

与这条线同步生长的，是另一股暗潮，经常凝成一句话：“既然AI能干，我就不学了。”我曾拿这句话问一个做外包的老手，他说：你不学，别人学。判断力、品味、连同结果的责任，都会流到那些肯付一点代价去调动工具的人手里。市场不负责同情，它只负责流通。

“既然AI会做，所以我不学了”——这句话听起来轻巧，其实只是把工作里的决策权和定价权，悉数托管给了别人的模型。

正确姿势很乏味，不玄学，也不热门：把它当作一台快得多的计算器。计算器不会替你做买不买房的决定，但能把账算完；模型也一样，它可以替你做初稿，但不能替你做主张。我现在做一篇报告，过去要从早写到晚，现在一小时生成初稿，剩下的时间全用来复核事实、追问需求、推敲战略。单位小时的价格，是这么抬上去的。

模型越来越便宜，用模型的大脑越来越贵。电钻便宜得很，可你不能让它自己盖出房子；同一个AI，对不肯学、不肯算的人，是滑梯；对拿得牢的人，是阶梯。区别不在模型，在握着手柄的那只手。

如今我常看着开头那位同事换一个新工具，关掉，在对话框里打同一句判词：还是不准。他已经越来越擅长证明工具不行。我倒觉得，他是在提前给“我不行”盖章。我至今没见过谁靠这种盖章保住了定价权；倒是见过越来越多把模型当计算器用的人，时薪一年比一年贵。老周上周又被叫去谈了一次薪。跟不上引擎的名单还在加长，至少目前，他还没有上榜。
