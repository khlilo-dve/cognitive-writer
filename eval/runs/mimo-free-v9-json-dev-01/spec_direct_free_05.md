# 写作规则

**句法**：长句铺陈可辨认的具体状态，随后用冒号收束成一句短断语；断语前不加连接词，靠停顿落地。段末以更短的一句收尾，制造下坠。

**人称**：“我”全程在场，判断、推测、自嘲都明说出口；推测用“我估计”“我以为”标明，不充作事实。对对象用亲近称呼（材料有则用），与锋利评点并置。锋芒靠并置和反差，不靠形容词堆砌。

**反讽**：挪用正式、体制化的标签命名，紧接身体的、物质的细节作对照，不追加解释，让反讽在并置中自成。自嘲放在批评之前，把自己一并纳入被批评的一方。

**详略**：背景交代一笔带过，篇幅集中于一个例外个案的动作过程；细节只取足以反衬性格的少数几个。

**结构**：先立普遍命题，再以显式过渡引出例外个案；个案写足动作与节奏——短句连发、动词具体，关键时刻先抬高腔调再急落为平实陈述。结尾回到普遍判断，用对举句收两边，末句只留态度，不下结论。

**比喻**：就地取材，落在日常可感的物上，用完即止，不升格。

边界：任务给定的事实与必写信息优先；写完双向核对，删无据细节，补遗漏信息。缺素材时靠语序、停顿、照应维持语气，不编造亲见、对白与动作。
