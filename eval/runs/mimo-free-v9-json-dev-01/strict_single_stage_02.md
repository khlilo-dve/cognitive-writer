# 旧物修理日那天，社区活动室

那天是社区的旧物修理日。地点是社区活动室。屋里开着顶灯，光线落在桌面上。窗外是白天。

桌上摆着两件旧物。一盏接触不良的台灯。一台转动缓慢的旧风扇。两件都旧，都还能通电。

两名志愿者坐在桌后来检查。来访的人站在桌边，可以旁观，也可以提问。有的只是看。有的开口问。

门外有人走过。屋里只剩桌面上的响动。

先看的是台灯。志愿者把台灯转过来，手指按在接线的位置。灯没有亮。再按一下，亮一下，又灭。开关被按了几次。检查停在这里。

接线松动。他把线一处一处按过，重新固定，再合上，插头接回去。灯亮了。一直亮着。台灯放在桌面，不再闪。

有人问风扇。志愿者打开外壳，看了转动的部分，说要更换零件。扇叶还是转得慢。零件不是当天能配上的。

当天没有合适的零件。工作人员把零件型号写下来，又写上后续的联系办法。没有人说这台风扇已经修好。

活动只提供检查和力所能及的修复。工作人员说明，不保证所有物品都能恢复。能修的当场修，修不了的登记下来。登记下来的，后面再联系。

旁观的人站着，轮流上前。问题一个接一个。有人问台灯是怎么弄的，有人问风扇是怎么回事。

有人问零件什么时候到。有人问要不要先买一台替代的。工作人员只说按写下的办法联系，别的话没有。

桌边有两种说法。一种要留着原物，修好接着用。另一种说等零件要等，买替代品也要挑，两头都要算。两边都没有再往下说。看替代品的人没有再问。

台灯的插头拔了下来，放回桌面。风扇留在原处，扇叶不动。两件旧物都在桌上。一件亮过。一件没有。

写着零件型号和联系办法的那行字停在纸上。

风扇没有再被开动。
