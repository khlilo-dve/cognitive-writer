# 如何读懂修理的边界

修理不等于修复。这句话得先摆清楚，不然你在社区活动室里看到的一切都会被误读。桌上摆着两件东西：一盏接触不良的台灯，一台转动缓慢的旧风扇。两名志愿者负责检查，你可以站在旁边看，也可以问。

先验证。台灯的毛病出在接线松动，志愿者重新固定接线，灯就恢复正常。这是当场见效的一类，我把它叫"当场摘因"——原因被摘掉，物件回到能用的状态。同样在现场，风扇转得慢，却不是线的问题，而是一个需要更换的零件，当天没有合适零件。工作人员登记下零件型号和后续联系办法，没有宣称已经修好。这是第二类，叫"留号待办"。这不是敷衍，是把"修好"和"在办"分成两件事。

再破谬。有人把修理当成万能承诺，以为送进去就该完好出来。但活动只提供检查和力所能及的修复，不保证所有物品都能恢复。修好的台灯与登记待办的风扇，其实是同一份边界的两面：能做的当场做，做不了的留下型号和联系办法。把这条线画明白，旁观和提问才有意义——你站在桌边看的不是魔术，是判断过程；问"这个能不能修"，得到的是"能"或"要等零件"，而不是一句含糊的安慰。

最后给路，也就是取舍本身。有人看重继续使用原物，宁可等一个零件也要让旧风扇继续转；也有人更在意等待与购买替代品之间的权衡，重新买一台更快。两种想法都站得住，区别只在你把这台旧风扇当记忆，还是当工具。看清这条边界，你才谈得上选。

划清修复边界。
