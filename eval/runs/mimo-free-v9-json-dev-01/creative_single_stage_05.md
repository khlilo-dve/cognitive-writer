# 留任的台灯

虚构场景

那天上午，我把台灯装进布袋，拎到社区活动室。它在书桌上站了九年，亮时亮，不亮时就黑着，随我熬夜也随我午睡，从不提要求，也从不邀功。

我管它叫老光。名字是我起的，它没反对过。旧货摊二十块钱换来的，编制外。

活动室长桌上排着别人的旧物：闹钟，收音机，电饭煲，一只掉了漆的随身听。两名志愿者摊开工具，先声明，只做检查和力所能及的修复，不保证所有物品都能恢复。

门口还摆着登记本，一个名字，一个电话，一件物的病史。

来的人不少，拎着各自的旧物，像带孩子来报名。

台灯的接线松了。志愿者拧了几下，灯重新亮起。我在旁边看了全程，其实只看懂了一个"松"字，剩下的都算陪审。

人好像都有替旧物安排前途的天性。东西一摆上长桌，便进了某种名单，等着被定性、被分流、被决定去留。调岗就是这么回事。

好在物件不会写申诉材料。

风扇不肯配合。它转得迟缓，一副拖延的样子。零件当天没有，工作人员把型号和后续联系办法登记在册，没有宣称已经修好。

它就那样慢转着，把一个下午拖成了一桩悬案。

围观的人开始提问。有人问能不能拆开看看，志愿者说拆了装不回去，就不再只是检查。有人问等零件划算，还是买个新的划算；有人说舍不得原物的手感，舍不得那圈磕痕，舍不得它在角落里站着的样子；有人当场掏手机比价，比着比着自己笑了，说修的钱够买半台。修理和替换的账，各人算法不同。

灯是留任了。风扇还在等一份不知何时到货的零件，姑且算停职留薪。

如今我遇事也先掂量换新，很少再拎着东西去排队。像那个肯坐下来等一根接线拧紧的下午，后来我再没碰到过。

老光还亮着。风扇的下落，我没有再问。
