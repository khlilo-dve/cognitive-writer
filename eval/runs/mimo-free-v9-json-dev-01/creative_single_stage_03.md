# 不肯说修好的人，才是会修的人

（虚构场景）

社区活动室的长桌前，站着的多半是抱旧物来的人。我们心里都默认一件事：修理等于复原，交出去，等一句"好了"就走。

**真正会修的人，恰恰不肯把话说满。** 桌上一盏接触不良的台灯，接线松动，志愿者重新固定，灯亮了；一台转得慢的旧风扇要换零件，当天偏偏没有合适的。那台没能当场转起来的风扇，算不算这次修理日的失败？

你若审视会发现，代价从来不在修好的那一半。倘若工作人员顺口说一句"回去应该没问题"，风扇被抱回去继续转，磨损一层层扩开，原本换一个零件就了结的事，最终演变成整机换新。而他只说了实话：登记零件型号，留下联系办法，承认今天办不到。原本可能多付一台风扇的代价，被压缩成一次等待。

围观的人会问，为什么不找个差不多的零件凑上。这个问题没有恶意，只是把两种价值摆在同一张桌上：有人看重继续用原物，把陪伴和熟悉放在前面；有人更在意等待与购买替代品的开销，把当下省事放在前面。谁都没错，区别只在于谁来承担判断。有人把风扇抱回去，有人把电话留下。

边界就是这么交出去的。活动只提供检查和力所能及的修复，不保证所有物品都能恢复原状。把这句先说出口，旁观与提问才落得实在，志愿者的沉默也就不必是心虚。

于是只剩三条克制：

1. **先说能做什么**，再谈修得好不好，让期待停在能力之内。
2. **把修不好的部分写下来**，登记零件型号与联系办法，让未完成的事有下文。
3. **把取舍留给持有者**，继续用原物还是等待替换，由他按自己的成本去称。

不是为了证明修理能替代一切，而是在坚持原物与放手换新之间取衡。修好是本事，说修不好，是更难的本事。
