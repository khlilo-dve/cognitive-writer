修不好，才是修理日最真的成果

我们总以为一场修理日的成色，取决于修好了几件东西。**能修好的越多越好，这个判断本身站不住。** 那么，一件被登记了零件型号却没能当场复原的旧风扇，凭什么也算成果？

因为它诚实。社区活动室的桌上摆着两件旧物：台灯接触不良，志愿者重新固定了接线，灯亮了；风扇转动缓慢，拆开看需要更换零件，当天没有合适的，工作人员记下零件型号与后续联系办法，没有宣称已经修好。前者是力所能及的动手，后者是力所不及的说明。原本一次修理只是为了恢复使用，最终演变成一场对修不上之物的坦白，代价反而最低。

台上这两件旧物，恰好摆出两种处境：一件的毛病落在一根接线上，动手就能归位；另一件的毛病落在缺件上，动手之外还要等。等待的长短、零件的难寻、替代品的价码，都落在物主肩上，不落在修理桌上。

反过来推：若为了让当天看起来圆满，含糊地宣称一切安好，原本属于台灯的信任，最终会被风扇下次的停转一并透支。边界一旦模糊，原本只是检查的善意，最终演变成替人作主的越界。你若审视会发现，旁观者围着桌子提问，问的从来不是手艺高低，而是这东西还值不值得等。有人看重继续使用原物，有人更在意等待与购买替代品之间怎么走，两种取舍都成立，但都该由物主自己掂量。

于是边界要先说出口：

1. **先声明只检查不担保**，活动提供检查与力所能及的修复，不保证每件物品恢复。
2. **能动手的当场动手**，接线松动就重新固定，让成果当场可见。
3. **动手不了的留下凭据**，登记零件型号与联系办法，把未完成写在明处。
4. **把取舍交还物主**，继续用、等待，还是另寻替代，不由修理者替人决定。

不是为了证明手艺而修，而是在继续使用与等待替代之间取衡。说清修不上，比修好更难。
