# 台灯亮了，风扇没有

社区活动室里办旧物修理日，桌上摊着两件待查的物件：一盏接触不良的台灯，一台转动缓慢的旧风扇。两名志愿者负责检查，来访者可以站在旁边看，也可以提问。规则说得很朴素——只做检查和力所能及的修复，不保证所有物品都能恢复：修东西从来不是许愿。我估计不少人是冲着"修好"来的，我自己也算其中一个，那就先在这里落空一次。

先说那个例外：被修好了的那件。台灯的毛病是接触不良，志愿者顺着线路往下查，找到接线松动的地方，动手把接线重新固定：灯恢复正常，亮了。整个过程没有奇迹，只有几下手上的活儿。它又能用了。

风扇是另一半答案。它转得慢，需要更换零件，而当天没有合适的零件。于是走的是填表：工作人员登记零件型号，留下后续联系办法，从头到尾没有宣称它已经修好。型号、联系、后续，字眼都端正，叶片一下没多转。

修复边界就在这个下午摊开。能修的当场修，修不了的写下来等：来访者在旁边看着，也提问，志愿者边检查边答，谁都不必许诺什么。旁观的人看得见过程，也就看得见界限。我以为这比什么都修好要老实。

至于留还是换，桌上那两件东西替人把问题摆了出来。有人重视继续使用原物，宁可等零件，宁可让风扇再慢一阵；有人更在意等待与购买替代品之间的取舍，与其耗着，不如换一台新的。我两边都懂，只是舍不得那点旧的用处。

台灯修好了继续亮，风扇没修好继续慢。修与换，一个留住原物，一个省下等待：都是为了让日子接着用。我偏向把旧的多留一会儿。
