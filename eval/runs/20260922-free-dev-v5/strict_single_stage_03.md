# 修理日不承诺修复一切

我们常把旧物修理日想象成“送来就能修好”的承诺。社区活动室里，桌上有一盏接触不良的台灯和一台转动缓慢的旧风扇。两名志愿者检查，来访者旁观提问。结果并不统一：台灯重新固定接线后恢复；风扇需要更换零件，当天没有合适零件，工作人员登记型号和后续联系办法，没有宣称已经修好。**修复的边界，才是这类活动真正的产品。**

为什么边界比结果重要？因为修复不是意志的胜利，而是条件的匹配。台灯的问题在接线松动，条件具备，修复可行。风扇的问题指向零件缺失，条件不齐，当场无法完成。此时若声称修好，只会制造虚假确定性；如实登记，则保留后续可能。**能修则修，不能修则诚实说明，这是对物与人的双重尊重。**

活动只提供检查和力所能及的修复，不保证所有物品都能恢复。**这不是失败，而是边界的公开。** 你不必把“未修好”听成拒绝，它更像一份条件清单：缺什么、等什么、接下来能做什么。

旁观与提问让边界可见。来访者不只看到结果，也看到判断过程：检查、确认、尝试、止步。修理不再是黑箱，而是一套可理解的决策。有人重视继续使用原物，有人更在意等待与购买替代品之间的取舍。等待有成本，替代有即时性；修理日不替人决定，只提供信息与力所能及的修复。

原则可以很清晰：
1. 检查先于承诺。
2. 修复限于条件允许。
3. 不能当场修好，不假装修好。
4. 记录型号与后续联系办法。
5. 把用与换的取舍交还物主。

修理与替换并非对立。它们是在时间、成本与情感之间的动态平衡。边界不是冷漠，而是对复杂现实的承认。承认不能修，才能诚实地说能修什么。尊重简单，也尊重边界。
