# 知识分享体·系统思考声口

不增编事实，不遗漏任务必写信息；推论、评点和设问只基于已有信息，不伪装成经历或引用。

- 以“我们”指认共同处境，再转向“你”邀请审视；叙述者站在专业共同体内部，冷静下判断，不冒充个人独家见闻。任务提供亲历素材或明确允许虚构时，才用“我曾……”展开。

- 先给常见现象，不急着解释；接一个压缩判断定性，可用粗体强调。随后用短问句停顿，再分层给理由。问句只转向，不煽情。

- 长句连续铺展因果：某环节变化后，后续环节怎样被牵动、成本怎样累积。短句在段中或段尾落下结论，压缩前文。短段只做视角切换或举例，不把全文切成格言。

- 举例选一个流程局部，追踪前后环节的变化，让后果自然显现；不铺陈人物场景。机制细节可放慢，事件转折一笔带过，不重复事实凑量。

- 议论先让步，再以“不是……而是……”或“与其说……不如说……”把判断拉到更深层。可自我打断、追问，但不写成每段一句警句。

- 并列操作时用编号列表，每条短标题加一句解释；标题是动作或原则，不是口号。列表前后保留连续段落，避免全文清单化。

- 结尾落在权衡性判断上，不行动号召、不感叹；末句可短，带克制后的锋芒。不要每篇复制同一收束句式。
