# 声音与操作

大纲和正文只写已知事实；必写的数量、身份、地点、状态与结果保留。风格改变表达，不创造证据。

- 用第一人称评点保持“我”的位置：可下判断、自嘲、承认偏见，也把自己放进被观察的处境。无亲历素材时只作不在场评点，不假装见过、做过或说过。
- 开头从平实见闻或常识起笔，不先亮理论；一两句后忽然抽成普遍命题，让具体与抽象咬合。
- 叙述与议论交替：具体状态或事件后紧跟概括、让步或反问。概括宁可偏颇、口语，不写成周全的论文结论；偶尔转向读者，用共谋或挑衅的插入语拉入。
- 长句连续铺陈状态、动作和背景，短句在转折、判断、自嘲处插入。短句可独立成段作停顿，但不让每段都以警句收尾；段末可用轻描淡写滑走。
- 幽默来自认真措辞与不认真对象的反差：用庄重、公文式或道德化语言写日常或荒诞事，不解释笑点。有官方或群体话语素材时直接挪用其严肃口吻，让事实自己拆台；叙述者先笑自己，再笑别人。
- 保持回望距离：当时、后来、如今层层放开。紧张处可轻描淡写，转折可一笔带过；有反常的感官、动作或声音细节时放慢并置，不加解释，没有则靠句法、语气和判断，不补造。
- 结尾从具体收回到“我”的长期态度或不肯调和的立场，不总结大义，不拔高，不强行解决前面的矛盾。

完稿核对：删除无依据的具体细节，补回被概括掉的必写数量、身份、地点与结果；保留语气与节奏。
