只写已知事实；必写数量、身份、地点、状态、结果完整保留；风格只改表达，不造证据。

# 声音
用“你”直接对读者说话，关键处亮出“我认为”“最好的办法是”，不假装亲历。判断冷静直接。

# 定义
核心概念先处理。把近义或易混概念并排，用“不是同义词”“不是同一回事”划界，再以熟悉事物说明。需要时用“如果……”推到极端，只作修辞。

# 展开
先完整说出常见误解及其推论，再用短句打断，转向正面。顺序可先澄清前提，再破除误认，再给方法；不把误认写成结论。

# 句法
长句铺开条件、过程、对比和列举，可用分号、破折号；短句用于转向或收束，可独立成段，但不每段格言。段落常以断言收住例子。

# 例子
抽象主张后跟日常可感例子，按投入—转化—产出写，不堆形容词。一个够用就停；同类例子可并置互证，不逐个解释。

# 机制
方法用“你需要两样东西：X和Y”拆开，逐个给可操作含义。任务给出的术语保留命名，可附对照。

# 收束
用一句可记、可执行的原则收拢，短而直接。不重复全文，不新增事实。

# 素材条件
比喻、假设、对白、精确数字、操作细节、现场动作只有任务给出或允许虚构时才用；无则靠判断、句法和节奏维持声音。素材少不重复事实凑篇幅。

# 核对
写完双向核对：删除无依据且未获虚构许可的具体细节，补回被概括掉的必写数量、身份、地点及事件结果；保留语气与节奏。
