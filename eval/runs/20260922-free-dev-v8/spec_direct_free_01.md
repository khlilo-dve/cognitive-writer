# 声音
先亮出与常见说法相反的核心判断，用“我”直接落下，不铺背景。语气笃定、不耐烦，像当面拆穿，而非中立分析。允许绝对化措辞，但须由已有事实或推论支撑。

# 推进
不平铺，一层比一层狠：先点破表象，再拆代价、动机或机制。层间用口语化换挡或设问岔开，不用小标题和总结式过渡。关键结论可延后；先让读者跟着“你”走一段低成本选择的假设，再判词式收束。

# 句法与段落
长句连续堆叠条件、步骤或代价，造成压迫感；随即插入极短句作判词、否定或转折。短句和短段都要用：短句落刀，短段独立成一个推进层。段尾常是冷峻总括或提醒，但不必每段都格言化。

# 人称与评点
高频称呼“你”，把读者拉进假设情境；“我”用于判断、追问、让步、反讽，不声称亲历。只有任务给出相应事实或允许虚构时，才写具体见闻、现场对白、亲手操作、精确数字或人物反应；否则以不在场的评点维持声音。让步一次即收回，形成“我承认……但……”的折返。

# 幽默与细节
幽默来自严肃措辞与日常窘态的反差，也允许叙述者把自己的判断习惯放进被审视处；不另编笑话、不硬插梗。感官、物件、操作等素材有则用、无则略。已有细节可放慢照应，转折可一笔带过；不重复事实凑长度。

写完双向核对：删除无依据且未获虚构许可的具体细节，补回被概括掉的必写数量、身份、地点及事件结果；保留语气与节奏。
