# eval 建设进度与下一步（临时文档）

> 目标：把 eval 从「描述性指标」升级成「能回答『改好还是改坏』的评价体系」。
> 核心原则：通用双核等权（50% 风格规范贴合度 + 50% 文章质量与活人感）。
> 测试集策略：5 个跨领域主题固定冻结，作为所有风格的通用生成基准。

---

## 1. 架构理解：为什么是「两套独立 eval」而不是「合成一套」？

### 结论先行
**必须保持为两套独立 eval，不能强行合成一套黑盒。**

### 原因剖析（解耦评测）
若合成端到端流水线（`样文 -> learn 提取 spec -> generate 拿 spec 生成文章 -> 评测文章`）：
- **归因模糊**：如果最终生成的文章质量差，你无法判断是 **learn 提取出的 spec 太烂**，还是 **generate 的 prompt 执行能力差**。
- **变量纠缠**：当你优化 `prompts/learn_style.md` 时，生成端如果是动态的，评测基准就会漂移。
- **正交职责**：
  - **Eval 1（生成端）** 评测的是 **“创作与表达力”**（输入结构化想法 + 任意风格 Spec，输出高质量、契合风格且有活人感的文章）。
  - **Eval 2（提取端）** 评测的是 **“信息逆向与抽象力”**（输入自然语言样文，输出精简可执行的 DSL/Spec 规则）。

## 3. Eval 1：通用双核 Rubric A 评分标准（50% 风格贴合 + 50% 活人质感）

评测输入：`[输入观点/主题] + [输入的风格规范 Style Spec] + [待评测文章]`

### 维度 1：破题与切入（Introduction Fidelity & Hook）
- **1分（差）**：AI 常见废话/背景铺垫开头（“在当今快节奏的社会中…”）；或完全违背 Spec 开头要求。
- **2分（生硬）**：开头生硬直蹦，缺乏张力；机械罗列概念，像机器吐字。
- **3分（及格）**：直接切入主题，但平铺直叙，吸引力和认知张力一般。
- **4分（良好）**：符合 Spec 开头要求，直入主题且有一定张力，开篇利落。
- **5分（卓越）**：第一句直击要害或颠覆直觉，既完全契合风格要求，又具备极强抓人的活人语感与认知悬念。

### 维度 2：论证与洞察（Argumentation & Depth）
- **1分（差）**：观点堆砌、逻辑跳跃、用结论证明结论，充满逻辑漏洞。
- **3分（及格）**：逻辑通顺，有因果推导，但属于大众常识，无明显认知增量。
- **5分（卓越）**：层层剥茧，直击底层运行机制；论据硬核、反常识且严丝合缝；极具批判性思考深度。

### 维度 3：节奏与句式（Rhythm & Syntax Fidelity）
- **1分（差）**：大长段堆砌、句子冗长缠绕；或者全文通篇平铺直叙，毫无起伏。
- **2分（典型扣分项）**：通篇平淡，缺乏长短句交错；未执行 Spec 要求的设问/自问自答、短句打断长逻辑；段落缺少呼吸感。
- **3分（及格）**：段落长度适中，有基本分段，但句式单调，节奏平稳无亮点。
- **4分（良好）**：良好执行 Spec 的句式（如设问、短段），长短句有起伏交错。
- **5分（卓越）**：极具呼吸感与推进力，单句成段与密集推导穿插自如，行云流水。

### 维度 4：人称与视角（Persona & Tone Fidelity）
- **1分（差）**：浓厚说教味、居高临下；或者充斥虚假互动（“大家觉得呢？”）。
- **2分（典型扣分项）**：第二人称“你”过度泛滥导致强烈的说教指责感；缺少真实第一人称“我”的视角与活人真诚感；人称单调呆板。
- **3分（及格）**：语气客观中立，挑不出大毛病，但缺乏鲜明的角色定位与老朋友对话感。
- **4分（良好）**：符合风格人称设定，视角稳定，说教感弱，语气克制笃定。
- **5分（卓越）**：人称转换自然（在讲个人判断与经历时自然用“我”，探讨时用“你”），达到同侪犀利交流的活人感，毫无谄媚与说教。

### 维度 5：用词与去 AI 味（Vocabulary & Humanness）
- **1分（差）**：命中禁用词（“综上所述”、“值得注意的是”等）；假大空翻译腔与大词空词泛滥。
- **2分（典型扣分项）**：举例极其假大空、属于只有 AI 才会举的模板化无聊例子（如动不动就是“不会函数”、“不会开车”等空洞抽象比喻）；句子生硬像蹦出来的。
- **3分（及格）**：无明显禁词，语言通畅，但用词平淡，缺乏生活真实的具象场景。
- **4分（良好）**：例子具象生动，白话与精准术语结合自然，无 AI 假大空套话。
- **5分（卓越）**：语言凝练如刀，去油去水；动词极度精准；案例鲜活真实且完全来自现实生活/硬核商业，活人感极强。

### 维度 6：结尾收束（Conclusion Fidelity）
- **1分（差）**：套路化总结（“总而言之…”）、强行煽情升华、打鸡血口号。
- **3分（及格）**：平稳收束，中规中矩，但缺乏余味。
- **5分（卓越）**：戛然而止或冷峻收刀，余音绕梁，把思考空间与行动裁量权彻底交还读者，极具分量。

## 5. 发现的 4 大共性核心硬伤（即 Prompt 迭代的明确靶心）

1. **“你”过度泛滥，缺少“我”（说教味根源）**：
   - 现有的 generation prompt 倾向于把读者当做训诫对象（“你以为…其实你只是…”），全文缺少以“我”为视角的个人经验或判断支撑，丧失了老朋友同侪交流的真诚感。
2. **段末频繁落“金句”（AI 最舒服的惯性节奏）**：
   - AI 倾向于在每一个段落末尾都强行递一句对仗整齐的漂亮金句，破坏了真人写作的松弛感与留白，甚至直接踩中 `## 禁止`（每段结尾落金句）。
3. **设问/自问自答利用不足（平铺直叙）**：
   - Spec 中明确鼓励频繁使用设问和短句打断长逻辑，但当前生成基本全是陈述句平推，导致推导节奏平淡。
4. **抽象模板化举例（AI 味根源）**：
   - 容易陷入“不会函数”、“不会开车”等缺乏烟火气的空洞比喻。
